<objective>
**As a** BombVault user, **I want to** skip cache-tagged folders per backup root, **so that** restic excludes CACHEDIR.TAG directories from this container's snapshots without me hand-writing exclude patterns.

This plan lands the RESTIC-01 backend slice end-to-end: the per-root CACHEDIR.TAG toggle persists as an append-only JSON map column on targets (D-07), arrives through an additive PATCH field on /api/containers/{name}, is served back on the mounts response, and compiles at backup time into the item-level boolean union that emits the constant restic flag --exclude-caches in BackupArgs (D-06). Option A threading (restic.Mode field, the documented Limits precedent) is locked: internal/backup stays untouched.

Purpose: The flag must reach argv through the same service-to-builder channel the 01-05 excludes use, with byte-identical argv when no root enables it.
Output: Migration v100, store setter, PATCH/mounts wire fields, Mode.ExcludeCaches, argv emission, all pinned by tests.
</objective>
