# Ξεκινώντας

Αυτή η σελίδα σας οδηγεί από ένα φρέσκο μηχάνημα Unraid μέχρι το πρώτο σας αντίγραφο ασφαλείας.

## Απαιτήσεις

| Απαίτηση | Σημειώσεις |
|---|---|
| **Unraid 6.12+** | Παλαιότερες εκδόσεις δεν έχουν δοκιμαστεί. |
| **Τοποθεσία αποθετηρίου restic** | Μια τοπική διαδρομή (συνιστάται: το array ή η cache σας), SMB, NFS, ή οποιοδήποτε backend rclone. |
| **Docker socket** | Προσαρτάται αυτόματα από το template (`/var/run/docker.sock`). |
| **Unraid flash** (`/boot`) | Προσαρτάται ολόκληρο αυτόματα από το template (`/boot` στο `/host/boot`). Τροφοδοτεί το αντίγραφο του flash και επιτρέπει σε ένα επαναφερμένο container να εμφανιστεί ξανά ως κανονική, επεξεργάσιμη εφαρμογή Unraid. |
| **KVM VMs** (προαιρετικά) | Το αντίγραφο των VM επικοινωνεί με το libvirt μέσω SSH, χωρίς προσάρτηση libvirt. Ρυθμίστε το στις Ρυθμίσεις (δείτε [Διαμόρφωση](configuration.md)). |

## Εγκατάσταση στο Unraid

Ο ευκολότερος δρόμος είναι μέσω **Community Applications**.

1. Ανοίξτε την καρτέλα **Apps** στο Unraid.
2. Αναζητήστε το **BombVault**.
3. Κάντε κλικ στο **Install**, ορίστε τις απαιτούμενες μεταβλητές (παρακάτω) και εφαρμόστε.

!!! tip "Χειροκίνητη εγκατάσταση template"
    Αν προτιμάτε να προσθέσετε το template με το χέρι:

    1. Πηγαίνετε στο **Docker, Add Container, Template repositories** και προσθέστε:
       ```
       https://github.com/junkerderprovinz/unraid-apps
       ```
    2. Αναζητήστε το **BombVault** στα Templates.
    3. Ορίστε τις απαιτούμενες μεταβλητές και κάντε κλικ στο **Apply**.

## Η μία απαιτούμενη ρύθμιση

Η μόνη μεταβλητή που πρέπει να ορίσετε είναι το `APP_KEY`, ένα δεκαεξαδικό μυστικό 32 byte (64 δεκαεξαδικοί χαρακτήρες) που χρησιμοποιείται για την παραγωγή του κωδικού του αποθετηρίου restic.

Δημιουργήστε ένα σε οποιοδήποτε μηχάνημα:

```bash
openssl rand -hex 32
```

Επικολλήστε το αποτέλεσμα στο πεδίο `APP_KEY` του template.

!!! danger "Μη χάσετε το APP_KEY σας"
    Η απώλεια του `APP_KEY` καθιστά τα κρυπτογραφημένα αντίγραφα ασφαλείας μη ανακτήσιμα. Αποθηκεύστε το σε ασφαλές μέρος, ξεχωριστά από τον διακομιστή. Μόλις το BombVault εκτελείται, χρησιμοποιήστε το **κιτ ανάκτησης κλειδιού κρυπτογράφησης** με ένα κλικ (δείτε [Εκτός τόπου & ανάκτηση](offsite-recovery.md)) για να αποθηκεύσετε το πλήρες πακέτο ανάκτησης.

Το template προσαρτά επίσης για εσάς το Docker socket, το flash (`/boot`) και τη ρίζα **Host Data** (`/mnt`). Οι *πηγές* και οι *προορισμοί* των αντιγράφων βρίσκονται και οι δύο κάτω από το Host Data. Για την πλήρη αναφορά μεταβλητών και τη ρύθμιση εκτός τόπου, δείτε [Διαμόρφωση](configuration.md).

## Πρώτη εκτέλεση

1. Ανοίξτε το περιβάλλον ιστού στο `https://<your-unraid-ip>:3443` (αυτο-υπογεγραμμένο πιστοποιητικό εξ ορισμού).
2. Στις **Ρυθμίσεις**, ενεργοποιήστε τους τομείς αντιγράφων που θέλετε (Containers, VMs, Flash, Config, Files) και επιλέξτε ένα χρώμα επισήμανσης.
3. Στην καρτέλα **Containers**, επιλέξτε ένα container και κάντε κλικ στο **Back up** για να δημιουργήσετε το πρώτο σας σημείο επαναφοράς. Οι διαδρομές αποθετηρίου έχουν προεπιλογή `/mnt/user/bombvault/{container,vms,flash,config,files}` και δημιουργούνται στο πρώτο αντίγραφο ασφαλείας.
4. Ρυθμίστε τον χρονοπρογραμματισμό από τις **Ρυθμίσεις, Χρονοδιαγράμματα**. Υπάρχει ένα *συμπερίληψη όλων στο χρονοδιάγραμμα* με ένα κλικ για containers και VMs.

!!! tip "Προαιρετικό: επιλέξτε σειρά αντιγράφων"
    Αν κάποια containers πρέπει πάντα να αντιγράφονται πριν από άλλα (για παράδειγμα μια βάση δεδομένων πριν από την εφαρμογή που τη χρησιμοποιεί), ανοίξτε τον πίνακα **σειράς αντιγράφων** στη σελίδα Containers και σύρετέ τα στην ακολουθία που θέλετε. Οι προγραμματισμένες και οι πολλαπλής επιλογής εκτελέσεις τότε την ακολουθούν· οτιδήποτε αφήσετε χωρίς σειρά αντιγράφεται με προτεραιότητα στα πιο καθυστερημένα, όπως πριν.

!!! note "Έλεγχος ενσωμάτωσης host"
    Ανοίξτε το `/spike` στο περιβάλλον ιστού αφού ξεκινήσει το container. Ανιχνεύει κάθε προσάρτηση και CLI (Docker socket, libvirt, restic, qemu-img, rclone) και αναφέρει τυχόν κομμάτια που λείπουν, ώστε να επιβεβαιώσετε ότι το container είναι σωστά συνδεδεμένο πριν βασιστείτε σε αυτό.

## Απλή έναντι Σύνθετης

Εξ ορισμού η διεπαφή δείχνει μόνο τα βασικά (αντίγραφο, επαναφορά, χρονοδιάγραμμα). Χρησιμοποιήστε τον διακόπτη **Simple / Advanced** στην πλαϊνή μπάρα για να αποκαλύψετε τα προχωρημένα χειριστήρια: διατήρηση, αντίγραφο εκτός τόπου, hooks πριν/μετά, επαναφορά σε επίπεδο αρχείου, ειδοποιήσεις, μετρικές Prometheus και τα εργαλεία ακεραιότητας/συντήρησης. Είναι προτίμηση ανά πρόγραμμα περιήγησης και ανενεργή εξ ορισμού, ώστε οι νεοφερμένοι να έχουν ένα καθαρό περιβάλλον και οι έμπειροι χρήστες να έχουν τα πάντα.

- Κολλήσατε κάπου; Δείτε την **[Αντιμετώπιση προβλημάτων](troubleshooting.md)**.
