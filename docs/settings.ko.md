# 설정

**설정**은 열네 개의 타일입니다. 각 타일은 카드로 이루어진 페이지이며, 모든 변경은 하는 즉시 기록됩니다. 컨트롤이 짧게 깜박이고, 서버가 거부하면 흔들립니다. 로그인이나 로그인 비밀번호처럼 반쯤 하다 저장하면 안전하지 않은 몇몇 창에는 **저장** 버튼이 남아 있습니다. 설명은 각 컨트롤 옆의 (i) 풍선에 있습니다.

설정 안 어디서든 `/` 또는 Ctrl+K를 누르면 모든 설정을 검색할 수 있으며, 이전 버전에서 페이지가 쓰던 이름으로도 찾을 수 있습니다. 타일의 순서는 **모양**에서 바꿀 수 있습니다. 페이지 옆의 타일 열이 페이지를 좁게 만드는 경우, 예를 들어 너비 약 1200픽셀의 창이나 휴대폰에서는 타일이 페이지 위의 띠가 되어 옆으로 스크롤됩니다.

이 페이지는 모든 타일과 그 카드를 나열하고, 각각을 깊이 설명하는 페이지로 연결합니다.

## 일반 {#general}

- **섹션**은 각 섹션을 켜거나 끕니다. **컨테이너**, **가상 머신**, **플래시**, **폴더**, **ZFS 데이터세트**, **셀프 백업**입니다. 꺼진 섹션은 항목 자체의 계획을 포함해 어떤 일정으로도 백업되지 않으며 그 항목은 세지 않습니다. **지금 백업**은 여전히 쓸 수 있습니다. **플래시**는 Unraid에서만 표시됩니다.
- **컨테이너**에는 **데이터베이스 자동 덤프**처럼 모든 컨테이너에 적용되는 것이 있습니다. 컨테이너 하나에 영향을 주는 것은 모두 그 컨테이너의 페이지에 있습니다. [데이터베이스 덤프](backups.md#database-dumps)를 참고하세요.

## 모양 {#look}

- **모양**: **언어**(42개 언어), **테마**(**어둡게**, **밝게**, **시스템**)와 그 아래에 있는, 어두운 테마가 보이는 동안 OLED와 AMOLED 화면에 진짜 검은색을 쓰는 **OLED**, **모서리**, **애니메이션**(**끄기**, **은은하게**, **격렬하게**, **폭풍**), 저장 확인 같은 성공 알림을 숨기는 **조용한 알림**, 그리고 타일을 누른 채 끌어서 자리에 놓거나 Alt와 화살표 키를 쓰는 **설정 페이지 순서**입니다.
- **레이블**: 컨트롤을 얼마나 보여 줄지이며, **버튼**, **사이드바**, **탭**, **하단 바**마다 따로 정합니다. **텍스트**, **텍스트와 기호**, **기호**, 또는 기호만 보여 주다가 가리키면 단어가 밀려 나오는 **반응형**입니다. **사이드바**는 데스크톱 레이아웃에만, **하단 바**는 휴대폰 레이아웃에만 영향을 줍니다.
- **색상**: **강조 색상** 하나, 또는 목록의 줄마다 여덟 가지 팔레트에서 자기 색을 받는 **무지개 모드**입니다. 무지개 모드에는 색이 천천히 다음 색으로 흐르는 **디스코 모드**, 줄의 색이 가리키거나 실행 중이거나 선택되었을 때만 보이는 **반응형 모드**, **색상 순환**, 그리고 **색상 팔레트** 자체가 추가됩니다. 강조 색상 맨 앞의 마술봉인 **시스템 색상**은 기기 고유의 색을 가져옵니다. Android 12 이상의 Android 앱에서는 Material You, Firefox와 Safari에서는 시스템 색상입니다. 기기에 그런 색이 있을 때만 나타납니다.

BombVault는 모양을 서버에 보관합니다. 처음 오는 브라우저는 그것을 이어받습니다. 단, **OLED**와 **시스템 색상**은 예외입니다. 화면에 따라 달라지므로 각 기기가 따로 보관합니다. 시스템이 움직임을 줄이도록 요청하면 항상 **애니메이션**보다 그것이 우선합니다.

## 일정 {#schedule}

**주**, **백업이 실행되는 시점**·**시작 후 놓친 백업 따라잡기**·**전후 명령**이 있는 **전체 백업**, **섹션별 오프사이트 복사**가 있는 **섹션별 일정**, **예약된 항목**, **백업 후 재시작**이 있는 **순서**, **중지 대신 스냅샷**, **백업 후 업데이트**, **백업 전 유휴 상태**입니다. [일정](schedules.md)을 참고하세요.

## 대상 {#storage-locations}

- **사이드바에도 표시**는 대상 페이지를 사이드바에 고정합니다.
- 대상 목록과 **대상 추가**. 누르면 대상의 페이지가 열립니다. [대상 페이지](offsite-recovery.md#location-page)를 참고하세요.
- **자격 증명**: 기본 별표가 있는 저장된 자격 증명입니다. [자격 증명](offsite-recovery.md#sign-ins)을 참고하세요.
- **섹션별 대상**: 모든 줄이 스위치인 3-2-1 흐름입니다. [섹션별 기본값](offsite-recovery.md#placement-defaults)을 참고하세요.
- **저장소**: 개별 항목을 위해 만든 저장소입니다. [항목별 배치](offsite-recovery.md#placement)를 참고하세요.
- **보존 기간**은 보존 정책을 정하는 대상으로 안내하며, **미리 보기**는 **다음 실행에서 제거될 항목**을 실제로 일어나기 전에 저장소별, 항목별로 보여 줍니다. 아무것도 바꾸지 않고 아무것도 잠그지 않으므로 백업이 실행 중일 때도 답합니다.
- **오프사이트 복사본**: 섹션마다 한 줄이며 **연결 테스트**, **지금 복제**, **설정** 또는 **편집**이 있습니다. [오프사이트 복사](offsite-recovery.md#off-site-copies)를 참고하세요.
- **오프사이트 대역폭**: 모든 복사에 적용되는 **업로드 제한 (KiB/s)**과 **다운로드 제한 (KiB/s)**입니다. 0은 제한 없음입니다.

Plex, Jellyfin, Emby가 스트리밍하는 동안 업로드 제한을 낮추는 **스트리밍** 카드는 대상 페이지 자체에 있습니다.

## 복원 {#restore}

- **복원** 페이지로 가는 링크.
- **복원 폴더**: 폴더로 복원할 때의 **기본 복원 폴더**이며, **섹션별 하위 폴더**와 섹션별 **예외**가 있습니다. [폴더로 복원하면 어디에 놓이는가](restore.md#folders)를 참고하세요.
- **컨테이너 레지스트리**: 스폰서 전용 `ghcr.io` 이미지 같은 비공개 레지스트리의 로그인 정보입니다. 복원은 없는 이미지를 받을 때, 백업 후 업데이트는 더 새로운 이미지를 확인할 때 이것을 씁니다. 공개 이미지는 없이도 받아집니다. **레지스트리 추가**에서는 공개 레지스트리, 자체 호스팅 레지스트리, 클라우드 제공업체의 레지스트리, 그리고 아무 주소나 쓸 수 있는 **다른 레지스트리**를 고를 수 있습니다.
- **긴급 상황용**: 로그인 비밀번호가 필요한 **복구 키트 다운로드**. [복구 키트](offsite-recovery.md#recovery-kit)를 참고하세요.

## 알림 {#notifications}

요약, **지연된 백업 보고**, **주간 요약**이 있는 **알림**, 그리고 **채널**입니다. **채널**은 Unraid, ntfy, Gotify, Discord, Slack, Matrix, 이메일, Apprise, webhook, Healthchecks 채널의 목록이며, 채널마다 자기 스위치, **알림**, **테스트 보내기**가 있습니다. [알림](notifications.md)을 참고하세요.

## 검증 {#verify}

- **백업 확인**: 섹션별로 마지막 `restic check`의 결과이며, 각 줄의 **더보기** 아래에 **잠금 해제**와 **정리**가 있습니다. **잠금 해제**는 오래된 잠금을 지우되 아직 갱신되고 있는 잠금은 그대로 두고, **정리**는 보관 규칙을 필요할 때 적용합니다.
- **자동 검사**: **데이터 표본 (%)**과 테스트 대상이 있는 예약된 복원 검사, 컨테이너 하나를 격리된 사본으로 복원해 시작해 보기까지 하는 **시작 테스트**, **예약된 오프사이트 DR 훈련**, 예약된 변조 테스트인 **삭제 방지 확인**입니다. [DR 훈련](offsite-recovery.md#dr-drills)과 [변조 테스트](offsite-recovery.md#tamper-test)를 참고하세요.
- **이상 징후**: 감지, 민감도, 어떤 결과가 메시지를 보내는지입니다. [이상 징후](anomalies.md)를 참고하세요.

## 보안 {#security}

- **비밀번호**: 로그인 비밀번호이며 최소 12자입니다. 바꾸거나 지울 때는 현재 비밀번호를 묻고, 2단계 인증이 켜져 있으면 코드도 묻습니다.
- **2단계 인증**: 비밀번호에 더해 인증 앱의 코드를 요구하며, 복구 코드 여덟 개가 한 번만 표시됩니다.
- **패스키**: 휴대폰, 노트북, 보안 키의 키로 로그인합니다. 실제 도메인 이름과 브라우저가 신뢰하는 인증서가 필요합니다.
- **Android 앱**: **그룹의 12개 단어로 휴대폰 페어링 허용**을 켜면 페어링한 휴대폰이 비밀번호 없이 로그인할 수 있습니다.
- **암호화**: 기본으로 켜져 있는 **백업 암호화**.

복구 키트나 키 보관처럼 로그인 비밀번호가 필요한 것이 여럿 있습니다. [보안 모델](configuration.md#security-model)을 참고하세요.

## 인스턴스 {#instances}

- **사이드바에도 표시**는 인스턴스 페이지를 사이드바에 고정합니다.
- **여러 서버**는 그룹의 구성 요소를 켭니다. 구성원마다 카드가 있는 페이지인 **인스턴스**, **수신기**, **가져오기**입니다. [인스턴스와 역할](offsite-recovery.md#roles)을 참고하세요.
- 켜진 구성 요소와 함께 인스턴스 페이지로 가는 링크.

## 페어링 {#pairing}

**문구 생성** 또는 **문구 입력**이 있는 **페어링**, 단계 카드, 이 인스턴스의 이름과 **알려진 주소**, 네 가지 형태와 **릴레이가 보는 것**이 있는 **릴레이** 카드, 그룹의 구성원, 그리고 SSH로 복제 대상을 쓰는 **BombVault 없는 ZFS 서버**입니다. [인스턴스 페어링](offsite-recovery.md#pairing)과 [ZFS 서버로 푸시](zfs-datasets.md#replica-push)를 참고하세요.

## 연동 {#integrations}

- **MCP 서버**: AI 어시스턴트용 키, **클라이언트 선택**, 각 키의 로그. [MCP 서버](mcp.md)를 참고하세요.
- **API 토큰**: 스크립트와 대시보드를 위한 이름 있는 토큰. [토큰](api.md#tokens)을 참고하세요.
- **서비스**: MQTT를 통한 **Home Assistant**, **네트워크에서 찾기**(`bombvault.local`로의 mDNS), Prometheus용 **/metrics 노출**과 **스크레이프 토큰 (선택)**. [Home Assistant](api.md#home-assistant)와 [네트워크에서 BombVault 찾기](api.md#mdns)를 참고하세요.
- **대시보드 위젯**: Homepage나 Heimdall처럼 iframe을 보여 주는 모든 대시보드를 위한 읽기 전용 토큰과 주소이며, 실시간 활동 로그만 보여 줍니다. [대시보드 위젯](api.md#dashboard-widget)을 참고하세요.
- **호스트 SSH**: VM과 ZFS 데이터세트 백업, Unraid 알림을 위한 BombVault의 공개 키와 **연결 테스트**. [VM 백업 가이드](vm-backup-ssh-setup.md)를 참고하세요.

## 앱 {#apps}

- **Android 앱**: 서버가 실행 중인 릴리스의 APK와 QR 코드, 그리고 F-Droid 목록. [Android 앱](android.md#install)을 참고하세요.
- **ParleyPort**: Unraid 템플릿과 이를 시작하는 Docker 명령이 있는 릴레이 컨테이너.
- **BombVault Widget**: BombVault의 활동 로그와 다음 실행을 보여 주는 Unraid 대시보드의 타일입니다. 호스트 SSH 연결이 있으면 카드가 플러그인을 직접 설치하고 제거합니다. 없으면 **Plugins, Install Plugin**에서 설치할 수 있도록 `.plg` 주소를 알려 줍니다.

## 시스템 {#system}

- **설정 내보내기 / 가져오기**: 전체 구성을 자격 증명을 포함하거나 제외한 이식 가능한 JSON 파일로 내보냅니다. 가져오기는 먼저 **이 파일의 내용**을 보여 주고 사라진 대상으로 가는 링크는 뺍니다. **age 로 내보내기 암호화**는 일반 내보내기, 플래시 ZIP, 복구 키트를 나열한 **age 수신자**용으로 봉인합니다. [이식 가능한 설정](configuration.md#portable-settings-export-and-import)을 참고하세요.
- **성능**: **CPU 스레드 (0 = 전체)**, `/config` 아래 restic 캐시의 **캐시 크기 제한 (MB, 0 = 무제한)**, 그리고 큰 백업이 메모리 부족으로 종료되는 대신 느려지게 하는 소프트 제한인 **백업당 메모리 제한 (MiB, 0 = 없음)**.

## 정보 {#info}

- **버전**: BombVault, GlimStone, restic, rclone이며, **업데이트 확인**과 아직 보지 않은 변경 수를 세어 주고 그 목록을 보여 주는 창을 여는 **신규**가 있습니다.
- **도움말**: **설명서**는 이 문서를 열고, **버그 신고**는 GitHub 이슈용으로 민감한 정보를 가린 ZIP을 내려받습니다. 로그인 비밀번호가 필요합니다.
- **BombVault 정보**: 프로젝트, 라이선스, 제작자에게 연락하는 방법.
