# ฟีเจอร์

แคตตาล็อกสั้น ๆ ของสิ่งที่ BombVault ทำได้ แต่ละบรรทัดลิงก์ไปยังหน้าที่อธิบายมัน

## ขอบเขตการสำรอง {#backup-scope}

- **คอนเทนเนอร์**: โฟลเดอร์ appdata และคำจำกัดความของคอนเทนเนอร์ เลือกโฟลเดอร์ต่อคอนเทนเนอร์ได้ [การสำรองข้อมูลและรายการ](backups.md#what-is-saved)
- **VMs**: image ดิสก์ XML และ UEFI NVRAM ผ่าน SSH ด้วยการปิดเครื่องอย่างนุ่มนวล สแนปช็อตแบบสด หรือเฉพาะบล็อกที่เปลี่ยน ครอบคลุม VM ที่มีสแนปช็อต Unraid และดิสก์บน zvol เต็มรูปแบบ [การสำรอง VM](vm-backup-ssh-setup.md)
- **Flash**: แฟลช USB ของ Unraid ทั้งหมด พร้อมการส่งออกเป็น zip ตามกำหนด [การสำรองข้อมูลและรายการ](backups.md#settings-tab)
- **สำรองข้อมูลตัวเอง**: การตั้งค่าและข้อมูลรับรองของ BombVault เอง [ตัวช่วยฉุกเฉิน](offsite-recovery.md#emergency)
- **โฟลเดอร์**: โฟลเดอร์ใดก็ได้บนเซิร์ฟเวอร์เป็นชุดโฟลเดอร์ [การเพิ่มโฟลเดอร์](backups.md#add)
- **ชุดข้อมูล ZFS**: ต้นไม้ชุดข้อมูลที่อ่านจากสแนปช็อตเดียว กู้คืนไฟล์เดี่ยวได้ และมีเรพลิกาบนเซิร์ฟเวอร์ ZFS ตัวที่สองให้เลือก [ชุดข้อมูล ZFS](zfs-datasets.md)
- **ไฟล์ดัมป์ฐานข้อมูล**: PostgreSQL, MySQL และ MariaDB ดัมป์จากเซิร์ฟเวอร์ที่กำลังรันเป็นจุดกู้คืนของตัวเอง [ไฟล์ดัมป์ฐานข้อมูล](backups.md#database-dumps)

## การสำรองข้อมูลและหน้าของรายการ {#backups}

- **รายการเดียว** พร้อมไทล์ **ตัวกรอง** **เรียงลำดับ** และ **ค้นหา** และการรันสิบสี่ครั้งล่าสุดของแต่ละแถวเป็นแถบ [รายการ](backups.md#list)
- **เลือกแบบตัวจัดการไฟล์** และสำรองหรือหยุดชั่วคราวชุดที่เลือกบนเซิร์ฟเวอร์ [เลือกหลายรายการ](backups.md#select)
- **หน้าต่อรายการ** พร้อม **การสำรองข้อมูล** **การตั้งค่า** และ **ยืนยัน** [หน้าของรายการ](backups.md#entry-page)
- **แท็กและเปรียบเทียบ** สำหรับสแนปช็อต และ **ส่งออก** เป็น tar, zip หรือที่เก็บ restic [แท็บการสำรองข้อมูล](backups.md#backups-tab)
- **รูปแบบการยกเว้น** พร้อมตัวอย่างสด และการยกเว้นที่แนะนำสำหรับแอปที่รู้จักกันดี [รูปแบบการยกเว้น](backups.md#excludes)
- **คำสั่งก่อนและหลัง** และ **หยุดคอนเทนเนอร์อื่น** พร้อมการรีสตาร์ทที่รอความพร้อมตามลำดับการพึ่งพา [คำสั่งและคอนเทนเนอร์อื่น](backups.md#commands)
- **เมื่อแอปไม่ว่าง**: การสำรองตามกำหนดรอ Plex, Jellyfin, Emby, การตรวจของคุณเอง หรือทราฟฟิกที่เงียบ และลองใหม่เอง [เมื่อแอปไม่ว่าง](backups.md#app-busy)
- **สแนปช็อตแทนการหยุด**: คอนเทนเนอร์บน ZFS หยุดเพียงไม่กี่วินาที [ตารางเวลา](schedules.md#snapshot-instead-of-stop)
- **การส่งออกแบบธรรมดา** ปิดผนึกด้วย age ได้ [การส่งออกแบบธรรมดา](backups.md#exports)

## การกู้คืน {#restore}

- **หนึ่งหน้าและหนึ่งหน้าต่าง** สำหรับทุกชนิด โดยเลือกข้อมูลสำรองที่แนะนำไว้ให้ [การกู้คืน](restore.md)
- **ข้างต้นฉบับ** เป็นค่าเริ่มต้น และ **แทนที่ต้นฉบับ** สำรองสถานะปัจจุบันก่อน [หน้าต่างการกู้คืน](restore.md#window)
- **ไฟล์เดี่ยว** ไปยังโฟลเดอร์หรือกลับที่เดิม [กู้คืนไฟล์เดียว](restore.md#example-single-file)
- **หลายรายการพร้อมกัน** แต่ละรายการจากข้อมูลสำรองที่แนะนำหรือจากช่วงเวลาเดียว [กู้คืนหลายรายการพร้อมกัน](restore.md#several)
- **สแตก Compose ทั้งชุด** เริ่มตามลำดับการพึ่งพา [กู้คืนสแตก](restore.md#stacks)
- **คอนเทนเนอร์และ VM ถูกสร้างใหม่** บน image ที่มันรัน พร้อม GPU ขีดจำกัด และลิงก์ [อะไรกลับมาบ้าง](restore.md#kinds)
- **การตรวจก่อนกู้คืน** และรายการสิ่งที่จะเปลี่ยน [หน้าต่างการกู้คืน](restore.md#window)
- **Flash เป็น ZIP** และวางปลั๊กอินทีละตัวกลับเข้าแฟลชที่ใช้งานอยู่ [อะไรกลับมาบ้าง](restore.md#kinds)
- **ZFS** เข้าชุดข้อมูลพร้อมสแนปช็อตเพื่อความปลอดภัย ไปยังโฟลเดอร์ หรือเข้าชุดข้อมูลใหม่พร้อมคุณสมบัติ [ชุดข้อมูล ZFS](zfs-datasets.md#restore)
- **ตัวช่วยฉุกเฉิน** สำหรับเซิร์ฟเวอร์ที่หายไป ด้วยชุดกู้คืน ผ่านกลุ่ม หรือด้วยคีย์ที่พิมพ์ใส่ [ตัวช่วยฉุกเฉิน](offsite-recovery.md#emergency)
- **จากโฟลเดอร์สำรองข้อมูลเก่า** และ **นำเข้าจากปลั๊กอิน Appdata.Backup** [แหล่งอื่น](restore.md#other-sources)

## ที่จัดเก็บและตารางเวลา {#storage-scheduling}

- **ปลายทางที่จัดเก็บ** ทุกชนิด: โฟลเดอร์ในเครื่อง SMB, WebDAV, SFTP, rest-server, S3, ไดรฟ์คลาวด์ และ rclone remote ใดก็ได้ [ปลายทางที่จัดเก็บ](offsite-recovery.md#destinations)
- **ข้อมูลรับรอง**: รายการเดียวพร้อมค่าเริ่มต้น [ข้อมูลรับรอง](offsite-recovery.md#sign-ins)
- **โฟลเดอร์ของตัวเอง** บนเซิร์ฟเวอร์นี้หรือในปลายทาง [โฟลเดอร์ของตัวเองของส่วน](offsite-recovery.md#own-folder)
- **3-2-1 เป็นโฟลว์** ที่ทุกบรรทัดเป็นสวิตช์ และ **การวางต่อรายการ** [การวางต่อรายการ](offsite-recovery.md#placement)
- **สำเนานอกสถานที่** ไปหลายปลายทางต่อส่วน พร้อมขีดจำกัดแบนด์วิดท์ การบีบอัด ชั้นเก็บแบบเย็น และการชะลอขณะที่ Plex สตรีม [สำเนานอกสถานที่](offsite-recovery.md#off-site-copies)
- **ที่เก็บโดยตรง** แสดงใต้ **สำรองข้อมูลมาที่นี่โดยตรง** [ที่เก็บโดยตรง](offsite-recovery.md#direct-repositories)
- **การเก็บรักษาเป็นไทม์ไลน์**: **สั้น** **สมดุล** **ยาว** หรือ **ค่าที่กำหนดเอง** ต่อปลายทาง พร้อมกฎต่อส่วน [เก็บไว้นานแค่ไหน](offsite-recovery.md#keep)
- **ย้ายประวัติของส่วน** และ **ลบปลายทาง** ทั้งแบบมีและไม่มีข้อมูลสำรอง [ย้ายและลบ](offsite-recovery.md#move-remove)
- **ตารางเวลาที่อ่านเป็นประโยค** แถบ **สัปดาห์** การสำรองข้อมูลทั้งหมด กำหนดการรายส่วน และกำหนดการของตัวเองต่อรายการ [ตารางเวลา](schedules.md)
- **ทำการสำรองที่พลาดไป** ลำดับที่กำหนดเอง และการอัปเดตหลังการสำรองที่สำเร็จ [ตารางเวลา](schedules.md)

## ข้อมูลเชิงลึก การตรวจสอบ และการเฝ้าระวัง {#insight-verification-monitoring}

- **ภาพรวม**: ส่วนหัวแสดงสถานะ **ต้องดูแล** **สถานะการป้องกัน** การคาดการณ์พื้นที่จัดเก็บ ประวัติ และการ์ดเสริม [ภาพรวม](overview.md)
- **การตรวจจับความผิดปกติ** ต่อรายการ ซึ่งเก็บข้อมูลสำรองเก่าไว้ด้วยเมื่อต้นทางยุบลง [ความผิดปกติ](anomalies.md)
- **การตรวจกู้คืน** หลังการสำรองครั้งแรก และ **ทดสอบการเริ่ม** ในสำเนาที่แยกไว้ [แท็บยืนยัน](backups.md#verify-tab)
- **การตรวจตามกำหนดและการทดสอบกู้คืน** จากสำเนานอกสถานที่ [การซ้อม DR](offsite-recovery.md#dr-drills)
- **ขนาดตามโฟลเดอร์** และเหตุที่การสำรองช้า [การรันบอกอะไรคุณ](backups.md#run-notes)
- **การแจ้งเตือน**: webhook, Gotify, Matrix, อีเมล, Apprise, Unraid และ Healthchecks พร้อมสรุปประจำสัปดาห์และรายงานที่ล่าช้า [การแจ้งเตือน](notifications.md)
- **Prometheus** อุปกรณ์ Home Assistant, HTTP API และ mDNS [API และการเชื่อมต่อ](api.md)
- **รายงานบั๊ก**: ZIP ที่ปกปิดข้อมูลสำหรับ issue บน GitHub [การแก้ปัญหา](troubleshooting.md#still-stuck)

## การป้องกันแรนซัมแวร์ {#ransomware-protection}

- **การป้องกันการลบ (append-only)** บังคับโดยฝั่งปลายทาง และพิสูจน์ด้วยการทดสอบการแก้ไขข้อมูล [การป้องกันการลบ](offsite-recovery.md#delete-protection-append-only)
- **ยอมรับโดยไม่มีการป้องกันการลบ** สำหรับที่ที่ปฏิเสธการลบไม่ได้ [การป้องกันการลบ](offsite-recovery.md#delete-protection-append-only)
- **เมื่อตั้งรหัสผ่านเข้าสู่ระบบไว้ การลบข้อมูลสำรองถาวรต้องลงชื่อเข้าใช้ด้วยตัวเอง** และโทรศัพท์ที่จับคู่ไว้ทำไม่ได้ [โมเดลความปลอดภัย](configuration.md#security-model)
- **ชุดกู้คืน** ปิดผนึกด้วย age ได้ และ **ผู้เก็บคีย์** ในกลุ่มของคุณ [ชุดกู้คืน](offsite-recovery.md#recovery-kit), [ผู้เก็บคีย์](offsite-recovery.md#key-keeper)

## หลายเซิร์ฟเวอร์ {#several-servers}

- **การจับคู่ด้วยคำสิบสองคำ** เข้ารหัสแบบ end-to-end ทั้งแบบตรงและผ่านรีเลย์ [การจับคู่อินสแตนซ์](offsite-recovery.md#pairing)
- **หน้าอินสแตนซ์** ที่แสดงกลุ่มเป็นตาข่าย พร้อมบทบาท **ตัวรับ** **ตัวดึง** **เซิร์ฟเวอร์ ZFS** และ **ผู้เก็บคีย์** [อินสแตนซ์และบทบาท](offsite-recovery.md#roles)
- **เซิร์ฟเวอร์รับ** ที่ตั้งค่าให้คุณในโหมด append-only [เซิร์ฟเวอร์รับ](offsite-recovery.md#receiving-server)

## ผู้ช่วย AI (MCP) {#mcp}

เซิร์ฟเวอร์ MCP ในตัวให้ผู้ช่วยอ่านสถานะการสำรอง ความครอบคลุม ประวัติการรัน และจุดกู้คืน และด้วยคีย์ที่อนุญาตก็เริ่มการสำรองได้ การกู้คืน การลบ prune และการตั้งค่ายังอยู่ในหน้าเว็บ [เซิร์ฟเวอร์ MCP](mcp.md)

## แอปและตัวเสริม {#apps}

- **แอป Android**: ทุกเซิร์ฟเวอร์ในกลุ่มของคุณบนโทรศัพท์ [แอป Android](android.md)
- **BombVault Widget**: ไทล์บนแดชบอร์ด Unraid [แอป](settings.md#apps)
- **บันทึกกิจกรรมแบบฝังได้** สำหรับแดชบอร์ดอย่าง Homepage หรือ Heimdall [วิดเจ็ตแดชบอร์ด](api.md#dashboard-widget)

## อื่น ๆ {#other}

- **42 ภาษา** สามธีม และป้ายกำกับ สี มุม และแอนิเมชันตามที่คุณเลือก [รูปลักษณ์](settings.md#look)
- **การตั้งค่าที่บันทึกเอง** พร้อมการค้นหาทั้งสิบสี่ไทล์ [การตั้งค่า](settings.md)
- **มีอะไรใหม่** หลังการอัปเดต พร้อมจุดสีเขียวที่สิ่งที่เปลี่ยน [ข้อมูล](settings.md#info)
- **HTTPS พร้อมใช้ทันที** และ healthcheck สำหรับเครื่องมือซ่อมตัวเอง [การกำหนดค่า](configuration.md#network)
