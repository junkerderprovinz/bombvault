# 設定

**設定**は 14 個のタイルでできています。各タイルはカードが並んだページで、変更はすべてその場で書き込まれ、コントロールが一瞬光ります。サーバーが拒否したときは揺れます。サインインやログインパスワードのように、途中で保存すると危険なウィンドウには、**保存**ボタンが残っています。説明は、各コントロールの横の (i) のバブルにあります。

設定のどこからでも `/` か Ctrl+K を押すと、すべての設定を検索できます。以前のバージョンでページが持っていた名前でも検索できます。タイルの順序は**外観**で変えられます。ページの横にタイルの列を置くと窮屈になる場合（幅 1200 ピクセル程度のウィンドウやスマートフォンなど）は、タイルがページの上の、横にスクロールできる帯になります。

## 一般 {#general}

- **セクション**は、**コンテナ**、**VM**、**フラッシュ**、**フォルダー**、**ZFS データセット**、**セルフバックアップ**の各セクションをオンまたはオフにします。オフのセクションは、項目独自のプランも含めて、どのスケジュールでもバックアップされず、その項目も数えられません。それでも**今すぐバックアップ**は使えます。**フラッシュ**は Unraid でのみ表示されます。
- **コンテナ**には、**データベースの自動ダンプ**など、すべてのコンテナに適用される設定があります。1 つのコンテナだけに影響することは、そのコンテナのページにあります。[データベースダンプ](backups.md#database-dumps)を参照してください。

## 外観 {#look}

- **外観**：**言語**（42 言語）、**テーマ**（**ダーク**、**ライト**、**システム**）とその下にある、ダークテーマが表示されているあいだ OLED と AMOLED の画面を真っ黒にする **OLED**、**角の形状**、**アニメーション**（**オフ**、**控えめ**、**ワイルド**、**嵐**）、保存の確認のような成功の通知を隠す**控えめな通知**、そしてタイルを押さえたままドラッグするか Alt と矢印キーで位置を決める**設定ページの並び順**。
- **ラベル**：コントロールをどこまで表示するかを、**ボタン**、**サイドバー**、**タブ**、**ボトムバー**ごとに設定します。**文字**、**文字と記号**、**記号**、または**反応型**で、反応型は記号だけを表示し、ポインターを合わせると言葉がスライドして現れます。**サイドバー**はデスクトップのレイアウトだけに、**ボトムバー**はスマートフォンのレイアウトだけに影響します。
- **カラー**：1 つの**アクセントカラー**、または**レインボーモード**です。後者では、一覧の各行が 8 色のパレットから独自の色をもらいます。レインボーモードでは、色が次の色へゆっくり滑らかに移る**ディスコモード**、行の色がポインターを合わせたとき、実行中、選択中にだけ表示される**リアクティブモード**、**カラーローテーション**、そして**カラーパレット**そのものが追加されます。アクセントカラーの先頭にある魔法の杖、**システムの色**は、デバイス自身の色を使います。Android 12 以降の Android アプリでは Material You、Firefox と Safari ではシステムの色です。デバイスにそうした色がある場合にだけ表示されます。

BombVault は見た目の設定をサーバーに保存します。初めて来たブラウザーは、それを引き継ぎます。ただし **OLED** と**システムの色**は例外で、画面によって変わるため、各デバイスが自分で保持します。システムが動きを減らすよう求めているときは、常にそれが**アニメーション**より優先されます。

## スケジュール {#schedule}

**週**、**バックアップの実行タイミング**と**起動後に実行されなかったバックアップを実行する**と**前後のコマンド**を持つ**全体バックアップ**、**セクションごとのオフサイトコピー**を持つ**セクションごとのスケジュール**、**スケジュール済みの項目**、**バックアップ後の再起動**を持つ**順序**、**停止の代わりにスナップショット**、**バックアップ後の更新**、**バックアップ前のアイドル**。[スケジュール](schedules.md)を参照してください。

## 保存先 {#storage-locations}

- **サイドバーにも表示**は、保存先のページをサイドバーに固定します。
- 保存先の一覧と、**保存先を追加**。クリックすると保存先のページが開きます。[保存先のページ](offsite-recovery.md#location-page)を参照してください。
- **認証情報**：保存された認証情報と、標準の星印。[認証情報](offsite-recovery.md#sign-ins)を参照してください。
- **セクションごとの保存先**：すべての行がスイッチになった 3-2-1 の流れ。[セクションごとの標準](offsite-recovery.md#placement-defaults)を参照してください。
- **リポジトリ**：個々の項目のために作られたリポジトリ。[項目ごとの配置](offsite-recovery.md#placement)を参照してください。
- **保持期間**は、保持ルールを設定する保存先を案内します。**プレビュー**は、リポジトリごと、項目ごとに、**次回の実行で削除されるもの**を、実行される前に表示します。何も変更せず、何もロックしないので、バックアップの実行中でも答えが返ります。
- **オフサイトコピー**：セクションごとに 1 行で、**接続をテスト**、**今すぐ複製**、**セットアップ**または**編集**があります。[オフサイトコピー](offsite-recovery.md#off-site-copies)を参照してください。
- **オフサイト帯域幅**：すべてのコピーに対する**アップロード制限 (KiB/s)** と**ダウンロード制限 (KiB/s)**。0 は無制限を意味します。

Plex、Jellyfin、Emby のストリーミング中にアップロード制限を下げる**ストリーミング**カードは、保存先のページ自体にあります。

## 復元 {#restore}

- **復元**ページへのリンク。
- **復元用フォルダー**：フォルダーへの復元用の**既定の復元フォルダー**と、**セクションごとのサブフォルダー**、セクションごとの**例外**。[フォルダーへの復元先](restore.md#folders)を参照してください。
- **コンテナレジストリ**：スポンサー限定の `ghcr.io` イメージのような、プライベートレジストリの認証情報です。復元では欠けているイメージの取得に、バックアップ後の更新では新しいイメージの確認に使われます。公開イメージは認証情報なしで取得されます。**レジストリを追加**には、公開レジストリ、セルフホストのもの、クラウドプロバイダーのもの、そして任意のアドレス用の**その他のレジストリ**があります。
- **緊急時用**：ログインパスワードが必要な**リカバリーキットをダウンロード**。[リカバリーキット](offsite-recovery.md#recovery-kit)を参照してください。

## 通知 {#notifications}

まとめ通知、**遅延したバックアップを報告**、**週次ダイジェスト**を持つ**通知**、そして**チャンネル**。チャンネルは Unraid、ntfy、Gotify、Discord、Slack、Matrix、メール、Apprise、Webhook、Healthchecks の一覧で、それぞれに専用のスイッチ、**通知する**、**テスト送信**があります。[通知](notifications.md)を参照してください。

## 検証 {#verify}

- **バックアップをチェック**：セクションごとの直近の `restic check` の結果。各行の**その他**の下に**ロック解除**と**整理**があります。**ロック解除**は古くなったロックを外し、更新が続いているロックはそのまま残します。**整理**は保持ルールを必要なときに適用します。
- **自動チェック**：**データサンプル (%)** とテスト対象を持つ、スケジュールされた復元チェック。1 つのコンテナを隔離したコピーに復元して起動する**起動テスト**。**スケジュールされたオフサイト DR ドリル**と、スケジュールされた改ざんテストである**削除保護のチェック**。[DR ドリル](offsite-recovery.md#dr-drills)と[改ざんテスト](offsite-recovery.md#tamper-test)を参照してください。
- **異常**：検出、感度、どの検出結果がメッセージを送るか。[異常](anomalies.md)を参照してください。

## セキュリティ {#security}

- **パスワード**：ログインパスワード（12 文字以上）。変更や削除には現在のパスワードが必要で、二段階認証がオンのときはコードも必要です。
- **二段階認証**：パスワードに加えて、認証アプリのコードを使います。8 つのリカバリーコードが一度だけ表示されます。
- **パスキー**：スマートフォン、ノートパソコン、セキュリティキーのキーでサインインします。実在するドメイン名と、ブラウザーが信頼する証明書が必要です。
- **Android アプリ**：**グループの12個の単語でスマートフォンをペアリングできる**を使うと、ペアリング済みのスマートフォンがパスワードなしでサインインできます。
- **暗号化**：標準でオンの**バックアップを暗号化**。

リカバリーキットや鍵の預け入れなど、いくつかの操作にはログインパスワードが必要です。[セキュリティモデル](configuration.md#security-model)を参照してください。

## インスタンス {#instances}

- **サイドバーにも表示**は、インスタンスのページをサイドバーに固定します。
- **複数のサーバー**は、グループの各部分をオンにします。メンバーごとのカードがあるページである**インスタンス**、**レシーバー**、**取得**です。[インスタンスとロール](offsite-recovery.md#roles)を参照してください。
- インスタンスのページへのリンクと、オンになっている部分。

## ペアリング {#pairing}

**フレーズを作成**または**フレーズを入力**を持つ**ペアリング**、手順のカード、このインスタンスの名前と**既知のアドレス**、4 つの形式と**リレーに見えるもの**を持つ**リレー**カード、グループのメンバー、そして SSH 経由のレプリカ宛先用の **BombVault のない ZFS サーバー**。[インスタンスのペアリング](offsite-recovery.md#pairing)と[ZFS サーバーへのプッシュ](zfs-datasets.md#replica-push)を参照してください。

## 連携 {#integrations}

- **MCP サーバー**：AI アシスタント用のキー、**クライアントを選択**、各キーのログ。[MCP サーバー](mcp.md)を参照してください。
- **API トークン**：スクリプトやダッシュボード用の名前付きトークン。[トークン](api.md#tokens)を参照してください。
- **サービス**：MQTT 経由の **Home Assistant**、（`bombvault.local` としての mDNS による）**ネットワークで見つける**、Prometheus 用の **/metrics を公開**と**スクレイプトークン（任意）**。[Home Assistant](api.md#home-assistant)と[ネットワーク上で BombVault を見つける](api.md#mdns)を参照してください。
- **ダッシュボードウィジェット**：Homepage や Heimdall のように iframe を表示するダッシュボード向けの、読み取り専用のトークンとアドレス。ライブのアクティビティログだけを表示します。[ダッシュボードウィジェット](api.md#dashboard-widget)を参照してください。
- **ホスト SSH**：VM と ZFS データセットのバックアップ、Unraid 通知に使う、BombVault の公開鍵と**接続をテスト**。[VM バックアップガイド](vm-backup-ssh-setup.md)を参照してください。

## アプリ {#apps}

- **Android アプリ**：サーバーが動かしているリリースの APK と QR コード、そして F-Droid の掲載ページ。[Android アプリ](android.md#install)を参照してください。
- **ParleyPort**：リレーのコンテナ。Unraid テンプレートと、起動する Docker コマンドがあります。
- **BombVault Widget**：Unraid ダッシュボードのタイルで、BombVault のアクティビティログと次回の実行を表示します。ホスト SSH 接続があれば、カードがプラグインのインストールと削除を自分で行います。なければ、**Plugins、Install Plugin** でインストールするための `.plg` のアドレスが渡されます。

## システム {#system}

- **設定のエクスポート / インポート**：設定全体を、認証情報あり、またはなしの持ち運べる JSON ファイルにします。インポートではまず**このファイルの内容**が表示され、なくなった保存先へのリンクは除外されます。**age でエクスポートを暗号化**は、通常のエクスポート、フラッシュの ZIP、リカバリーキットを、指定した **age の受信者**向けに暗号化します。[持ち運べる設定](configuration.md#portable-settings-export-and-import)を参照してください。
- **パフォーマンス**：**CPU スレッド数 (0 = すべて)**、`/config` にある restic のキャッシュ用の**キャッシュサイズ上限（MB、0 = 無制限）**、そして**バックアップごとのメモリ上限 (MiB, 0 = なし)**。最後のものはソフトな上限で、大きなバックアップがメモリ不足で強制終了されるのではなく、速度を落とすようにします。

## 情報 {#info}

- **バージョン**：BombVault、GlimStone、restic、rclone のバージョンと、**更新を確認**、そしてまだ見ていない変更を数えて、それを一覧するウィンドウを開く**新規**。
- **ヘルプ**：**マニュアル**はこのドキュメントを開き、**バグ報告**は GitHub の issue 用に情報を伏せた ZIP をダウンロードします。ログインパスワードが必要です。
- **BombVault について**：プロジェクト、そのライセンス、作者への連絡方法。
