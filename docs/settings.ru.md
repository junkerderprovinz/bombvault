# Настройки

**Настройки** состоят из четырнадцати плиток. Каждая плитка — страница с карточками, и каждое изменение записывается сразу, с короткой вспышкой на элементе, или дрожью, если сервер его отклонил. У нескольких окон остаётся кнопка **Сохранить**, потому что сохранить их наполовину было бы небезопасно, например вход или пароль для входа. Пояснения лежат в подсказках (i) рядом с каждым элементом.

Нажмите `/` или Ctrl+K в любом месте настроек, чтобы искать по всем настройкам, в том числе по названиям, которые страницы носили в прежних версиях. Порядок плиток можно изменить в разделе **Внешний вид**. Там, где колонка плиток рядом со страницей сжимала бы её, например в окне шириной около 1200 пикселей или на телефоне, плитки превращаются в ленту над страницей, которая прокручивается вбок.

Эта страница перечисляет каждую плитку и её карточки и ведёт на страницу, которая объясняет каждую из них подробно.

## Общие {#general}

- **Разделы** включает или выключает каждый раздел: **Контейнеры**, **Виртуальные машины**, **Flash**, **Папки**, **Наборы данных ZFS** и **Автобэкап**. Выключенный раздел не копируется ни по одному расписанию, включая собственный план записи, и его записи не учитываются. **Создать резервную копию** по-прежнему работает. **Flash** виден только в Unraid.
- **Контейнеры** содержит то, что относится ко всем контейнерам, например **Автоматические дампы баз данных**. Всё, что влияет на один контейнер, лежит на его странице. См. [Дампы баз данных](backups.md#database-dumps).

## Внешний вид {#look}

- **Внешний вид**: **Язык** (42 языка), **Тема** (**Тёмная**, **Светлая** или **Системная**), **Углы**, **Анимация** (**Выкл.**, **Слабое**, **Буйное** или **Штормовое**), **Тихие уведомления**, которые скрывают сообщения об успехе вроде подтверждений сохранения, и **Порядок страниц настроек**, где вы берёте плитку и перетаскиваете её на место или используете Alt и клавиши со стрелками.
- **Подписи**: сколько показывать у элемента управления, отдельно для **Кнопки**, **Боковая панель**, **Вкладки** и **Нижняя панель**: **Текст**, **Текст и символ**, **Символ** или **Реактивный**, который показывает один символ и выдвигает слова, когда вы наводите курсор. **Боковая панель** влияет только на раскладку для компьютера, а **Нижняя панель** только на раскладку для телефона.
- **Цвета**: один **Акцентный цвет** или **Режим радуги**, где каждая строка списка получает свой цвет из палитры из восьми. Режим радуги добавляет **Режим диско**, где цвета медленно переходят к следующему, **Реактивный режим**, где цвет строки виден, только пока вы наводите на неё курсор, она идёт или выбрана, **Ротация цвета** и саму **Цветовая палитра**.

BombVault хранит внешний вид на сервере. Браузер, который заходит впервые, перенимает его. Когда ваша система просит меньше движения, это всегда важнее, чем **Анимация**.

## Места назначения {#storage-locations}

- **Показывать также в боковой панели** закрепляет страницу мест назначения в боковой панели.
- Список ваших мест назначения с кнопкой **Добавить место назначения**. Щелчок открывает страницу места назначения, см. [Страница места назначения](offsite-recovery.md#location-page).
- **Учётные данные**: сохранённые учётные данные со звёздочкой по умолчанию, см. [Учётные данные](offsite-recovery.md#sign-ins).
- **Места назначения по разделам**: схема 3-2-1, где каждая строка — переключатель, см. [Значения по умолчанию для разделов](offsite-recovery.md#placement-defaults).
- **Репозитории**: репозитории, созданные для отдельных записей, см. [Размещение для отдельной записи](offsite-recovery.md#placement).
- **Как долго хранить** указывает на места назначения, где задано хранение, а **Предпросмотр** показывает **Что удалит следующий запуск** по каждому репозиторию и каждой записи, прежде чем это произойдёт. Он ничего не меняет и ничего не блокирует, поэтому отвечает даже во время копирования.
- **Внешние копии**: по одной строке на раздел с **Проверить соединение**, **Реплицировать сейчас** и **Настроить** или **Изменить**, см. [Внешние копии](offsite-recovery.md#off-site-copies).
- **Внешняя пропускная способность**: **Лимит отдачи (KiB/s)** и **Лимит загрузки (KiB/s)** для каждой копии. 0 означает без ограничений.

Карточка **Стриминг**, которая снижает лимит отдачи, пока Plex, Jellyfin или Emby транслируют, находится на самой странице мест назначения.

## Восстановление {#restore}

- Ссылка на страницу **Восстановление**.
- **Папки для восстановления**: **Папка восстановления по умолчанию** для восстановления в папку, с **Подпапка для каждого раздела** и **Исключение** для раздела. См. [Куда попадает восстановление в папку](restore.md#folders).
- **Реестры контейнеров**: учётные данные для частных реестров, например образа `ghcr.io`, доступного только спонсорам. Восстановление использует их, чтобы скачать недостающий образ, а обновление после копии, чтобы проверить более новый. Публичные образы скачиваются без них. **Добавить реестр** предлагает публичные реестры, собственные, реестры облачного провайдера и **Другой реестр** для любого адреса.
- **На экстренный случай**: **Скачать набор для восстановления**, для чего нужен пароль для входа. См. [Набор для восстановления](offsite-recovery.md#recovery-kit).

## Уведомления {#notifications}

**Уведомления** с **Уведомлять**, сводками, **Сообщать о просроченных копиях**, **Уведомления Unraid** и **Еженедельная сводка**, **Каналы** с Webhook, Apprise, Matrix, Gotify и эл. почтой (SMTP) и **Healthchecks**. См. [Уведомления](notifications.md).

## Проверка {#verify}

- **Проверить резервные копии**: результат последнего `restic check` по каждому разделу, с **Разблокировать** и **Очистить** под **Ещё** в каждой строке. **Разблокировать** снимает устаревшую блокировку, а **Очистить** применяет правила хранения по требованию.
- **Автоматические проверки**: плановая проверка восстановления с её **Выборка данных (%)** и целями теста, **Тест запуска**, который ещё и восстанавливает один контейнер в изолированную копию и запускает его, **Запланированная внешняя DR-проверка** и **Проверять защиту от удаления**, плановый тест на подделку. См. [DR-проверки](offsite-recovery.md#dr-drills) и [Тест на подделку](offsite-recovery.md#tamper-test).
- **Аномалии**: обнаружение, чувствительность и какие находки отправляют сообщение. См. [Аномалии](anomalies.md).

## Безопасность {#security}

- **Пароль**: пароль для входа, не короче 12 символов. Чтобы его изменить или убрать, нужен текущий пароль и, если включена двухфакторная аутентификация, код.
- **Двухфакторная аутентификация**: код из приложения-аутентификатора поверх пароля, с восемью кодами восстановления, которые показываются один раз.
- **Ключи доступа**: вход с помощью ключа на телефоне, ноутбуке или аппаратном ключе. Им нужны настоящее доменное имя и сертификат, которому доверяет браузер.
- **Приложение для Android**: **Телефоны можно сопрягать по двенадцати словам группы** позволяет сопряжённому телефону входить без пароля.
- **Шифрование**: **Шифровать копии**, по умолчанию включено.

Нескольким действиям нужен пароль для входа, например набору для восстановления, передаче ключей на хранение и окончательному удалению копий. См. [Модель безопасности](configuration.md#security-model).

## Интеграции {#integrations}

- **Сервер MCP**: ключи для ИИ-помощников, **Выбрать клиент** и журнал каждого ключа. См. [Сервер MCP](mcp.md).
- **Токены API**: именованные токены для скриптов и дашбордов. См. [Токены](api.md#tokens).
- **Сервисы**: **Home Assistant** через MQTT, **Поиск в сети** (mDNS как `bombvault.local`) и **Публиковать /metrics** для Prometheus с **Токен сбора (необязательно)**. См. [Home Assistant](api.md#home-assistant) и [Найти BombVault в сети](api.md#mdns).
- **Виджет для дашборда**: токен только для чтения и адрес для любого дашборда, который показывает iframe, например Homepage или Heimdall, только с живым журналом активности. См. [Виджет для дашборда](api.md#dashboard-widget).
- **SSH хоста**: открытый ключ BombVault и **Проверить соединение**, для копий виртуальных машин и наборов данных ZFS и для уведомлений Unraid. См. [руководство по копированию виртуальных машин](vm-backup-ssh-setup.md).

## Приложения {#apps}

- **Приложение для Android**: APK для версии, с которой работает ваш сервер, с QR-кодом и страница в F-Droid. См. [Приложение для Android](android.md#install).
- **ParleyPort**: контейнер-ретранслятор с шаблоном Unraid и командой Docker, которая его запускает.
- **BombVault Widget**: плитка на панели Unraid с журналом активности BombVault и следующим запуском. При SSH-соединении с хостом карточка сама устанавливает и удаляет плагин. Без него она выдаёт адрес `.plg`, который нужно установить в **Plugins, Install Plugin**.

## Система {#system}

- **Экспорт / импорт настроек**: вся ваша конфигурация в переносимом файле JSON, с учётными данными или без них. Импорт сначала показывает **Этот файл содержит** и пропускает ссылки на места назначения, которых больше нет. **Шифровать экспорты с помощью age** запечатывает обычные экспорты, ZIP флешки и набор для восстановления для **Получатели age**, которых вы перечислите. См. [Переносимые настройки](configuration.md#portable-settings-export-and-import).
- **Производительность**: **Потоки ЦП (0 = все)**, **Предел размера кэша (МБ, 0 = без ограничений)** для кэша restic в `/config` и **Лимит памяти на одно копирование (MiB, 0 = нет)**, мягкий лимит, который заставляет большую копию замедлиться, а не быть завершённой из-за нехватки памяти.
