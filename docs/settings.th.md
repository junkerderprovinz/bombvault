# การตั้งค่า

**การตั้งค่า** มีสิบสี่ไทล์ แต่ละไทล์เป็นหน้าของการ์ด และทุกการเปลี่ยนแปลงถูกเขียนทันทีที่ทำ โดยตัวควบคุมจะกะพริบสั้น ๆ หรือสั่นเมื่อเซิร์ฟเวอร์ปฏิเสธ บางหน้าต่างยังมีปุ่ม **บันทึก** เพราะการบันทึกครึ่งทางไม่ปลอดภัย เช่น การลงชื่อเข้าใช้หรือรหัสผ่านเข้าสู่ระบบ คำอธิบายอยู่ในบับเบิล (i) ข้างตัวควบคุมแต่ละอัน

กด `/` หรือ Ctrl+K ที่ไหนก็ได้ในการตั้งค่าเพื่อค้นหาทั้งหมด รวมถึงชื่อที่หน้าเคยใช้ในเวอร์ชันก่อน ๆ เปลี่ยนลำดับของไทล์ได้ที่ **รูปลักษณ์** ในที่ที่คอลัมน์ไทล์ข้างหน้าจะทำให้หน้าแคบเกินไป เช่นหน้าต่างกว้างราว 1200 พิกเซลหรือบนโทรศัพท์ ไทล์จะกลายเป็นแถบเหนือหน้าที่เลื่อนไปด้านข้างได้

![การตั้งค่าที่เปิดไทล์ทั่วไป](assets/screenshots/getting-started/settings-rail-dark.png#only-dark)
![การตั้งค่าที่เปิดไทล์ทั่วไป](assets/screenshots/getting-started/settings-rail-light.png#only-light)

หน้านี้ลิสต์ทุกไทล์และการ์ดของมัน พร้อมลิงก์ไปยังหน้าที่อธิบายแต่ละอันอย่างละเอียด

## ทั่วไป {#general}

- **ส่วน** เปิดหรือปิดแต่ละส่วน ได้แก่ **คอนเทนเนอร์**, **VMs**, **Flash**, **โฟลเดอร์**, **ชุดข้อมูล ZFS** และ **สำรองข้อมูลตัวเอง** ส่วนที่ปิดจะไม่ถูกสำรองตามกำหนดการใดเลย รวมถึงกำหนดการของรายการเอง และรายการของมันไม่นับ **สำรองข้อมูลเดี๋ยวนี้** ยังใช้ได้ **Flash** แสดงบน Unraid เท่านั้น
- **คอนเทนเนอร์** เก็บสิ่งที่ใช้กับทุกคอนเทนเนอร์ เช่น **ดัมป์ฐานข้อมูลอัตโนมัติ** อะไรที่กระทบคอนเทนเนอร์เดียวอยู่ที่หน้าของมัน ดู [ไฟล์ดัมป์ฐานข้อมูล](backups.md#database-dumps)

## รูปลักษณ์ {#look}

- **รูปลักษณ์**: **ภาษา** (42 ภาษา), **ธีม** (**มืด**, **สว่าง** หรือ **ระบบ**) พร้อม **OLED** ที่อยู่ด้านล่าง ซึ่งให้สีดำสนิทกับหน้าจอ OLED และ AMOLED ตราบที่ธีมมืดแสดงอยู่, **มุม**, **แอนิเมชัน** (**ปิด**, **นุ่มนวล**, **ดุเดือด** หรือ **พายุ**), **การแจ้งเตือนแบบเงียบ** ซึ่งซ่อนการแจ้งความสำเร็จอย่างการยืนยันการบันทึก และ **ลำดับของหน้าการตั้งค่า** ที่คุณกดไทล์ค้างแล้วลากไปวาง หรือใช้ Alt กับปุ่มลูกศร
- **ป้ายกำกับ**: ตัวควบคุมแสดงมากแค่ไหน แยกสำหรับ **ปุ่ม**, **แถบด้านข้าง**, **แท็บ** และ **แถบด้านล่าง** ได้แก่ **ข้อความ**, **ข้อความและสัญลักษณ์**, **สัญลักษณ์** หรือ **ตอบสนอง** ซึ่งแสดงเฉพาะสัญลักษณ์และเลื่อนข้อความเข้ามาเมื่อคุณชี้ **แถบด้านข้าง** มีผลกับเลย์เอาต์เดสก์ท็อปเท่านั้น และ **แถบด้านล่าง** กับเลย์เอาต์โทรศัพท์เท่านั้น
- **สี**: **สีเน้น** หนึ่งสี หรือ **โหมดสายรุ้ง** ที่แต่ละแถวของรายการได้สีของตัวเองจากจานสีแปดสี โหมดสายรุ้งเพิ่ม **โหมดดิสโก้** ที่สีค่อย ๆ เลื่อนไปสีถัดไป **โหมดตอบสนอง** ที่สีของแถวแสดงเฉพาะตอนที่คุณชี้ มันกำลังรัน หรือถูกเลือก **การหมุนสี** และ **จานสี** เอง ไม้กายสิทธิ์ที่อยู่ต้นแถวสีเน้น คือ **สีของระบบ** ซึ่งใช้สีของอุปกรณ์เอง ได้แก่ Material You ในแอป Android ตั้งแต่ Android 12 และสีของระบบใน Firefox และ Safari ตัวเลือกนี้จะแสดงเฉพาะเมื่ออุปกรณ์มีสีแบบนั้น

BombVault เก็บรูปลักษณ์ไว้บนเซิร์ฟเวอร์ เบราว์เซอร์ที่มาครั้งแรกจะรับค่านั้นไป ยกเว้น **OLED** และ **สีของระบบ** ที่แต่ละอุปกรณ์เก็บไว้เอง เพราะขึ้นอยู่กับหน้าจอของอุปกรณ์นั้น เมื่อระบบของคุณขอให้ลดการเคลื่อนไหว สิ่งนั้นชนะ **แอนิเมชัน** เสมอ

## ตารางเวลา {#schedule}

**สัปดาห์**, **สำรองข้อมูลทั้งหมด** พร้อม **เวลาที่สำรองข้อมูลทำงาน**, **ทำการสำรองข้อมูลที่พลาดไปหลังเริ่มระบบ** และ **คำสั่งก่อนและหลัง**, **กำหนดการรายส่วน** พร้อม **สำเนานอกสถานที่รายส่วน**, **รายการที่อยู่ในกำหนดการ**, **ลำดับ** พร้อม **รีสตาร์ทหลังการสำรองข้อมูล**, **สแนปช็อตแทนการหยุด**, **อัปเดตหลังการสำรองข้อมูล** และ **ความว่างก่อนสำรองข้อมูล** ดู [ตารางเวลา](schedules.md)

## ปลายทางที่จัดเก็บ {#storage-locations}

- **แสดงในแถบด้านข้างด้วย** ปักหมุดหน้าปลายทางที่จัดเก็บไว้ในแถบด้านข้าง
- รายการปลายทางที่จัดเก็บของคุณ พร้อม **เพิ่มปลายทาง** คลิกเพื่อเปิดหน้าของปลายทางนั้น ดู [หน้าของปลายทางที่จัดเก็บ](offsite-recovery.md#location-page)
- **ข้อมูลรับรอง**: ข้อมูลรับรองที่บันทึกไว้พร้อมดาวค่าเริ่มต้น ดู [ข้อมูลรับรอง](offsite-recovery.md#sign-ins)
- **ปลายทางแยกตามส่วน**: โฟลว์ 3-2-1 ที่ทุกบรรทัดเป็นสวิตช์ ดู [ค่าเริ่มต้นรายส่วน](offsite-recovery.md#placement-defaults)
- **ที่เก็บข้อมูล**: ที่เก็บที่สร้างสำหรับรายการเดี่ยว ดู [การวางต่อรายการ](offsite-recovery.md#placement)
- **เก็บไว้นานแค่ไหน** ชี้ไปที่ปลายทางที่จัดเก็บ ซึ่งเป็นที่ตั้งการเก็บรักษา และ **ดูตัวอย่าง** แสดง **สิ่งที่รอบถัดไปจะลบออก** แยกตามที่เก็บและตามรายการ ก่อนที่มันจะเกิดขึ้น ไม่เปลี่ยนอะไรและไม่ล็อกอะไร จึงตอบได้แม้ขณะที่การสำรองกำลังรัน
- **สำเนานอกสถานที่**: หนึ่งแถวต่อส่วน พร้อม **ทดสอบการเชื่อมต่อ**, **จำลองตอนนี้** และ **ตั้งค่า** หรือ **แก้ไข** ดู [สำเนานอกสถานที่](offsite-recovery.md#off-site-copies)
- **แบนด์วิดท์นอกสถานที่**: **ขีดจำกัดการอัปโหลด (KiB/s)** และ **ขีดจำกัดการดาวน์โหลด (KiB/s)** สำหรับทุกการคัดลอก 0 หมายถึงไม่จำกัด

การ์ด **สตรีมมิง** ซึ่งลดขีดจำกัดการอัปโหลดขณะที่ Plex, Jellyfin หรือ Emby สตรีมอยู่ ตั้งอยู่ในหน้าปลายทางที่จัดเก็บเอง

## การกู้คืน {#restore}

- ลิงก์ไปยังหน้า **การกู้คืน**
- **โฟลเดอร์สำหรับการกู้คืน**: **โฟลเดอร์กู้คืนเริ่มต้น** สำหรับการกู้คืนไปยังโฟลเดอร์ พร้อม **โฟลเดอร์ย่อยต่อส่วน** และ **ข้อยกเว้น** ต่อส่วน ดู [การกู้คืนไปยังโฟลเดอร์ไปที่ไหน](restore.md#folders)
- **Registry ของ container**: ข้อมูลรับรองสำหรับ registry ส่วนตัว เช่น image `ghcr.io` ที่ต้องเป็นผู้สนับสนุน การกู้คืนใช้มันเพื่อดึง image ที่ขาดไป และการอัปเดตหลังการสำรองใช้เพื่อตรวจหาอันที่ใหม่กว่า image สาธารณะดึงได้โดยไม่ต้องใช้ **เพิ่ม registry** มี registry สาธารณะ registry ที่โฮสต์เอง registry ที่ผู้ให้บริการคลาวด์ และ **registry อื่น** สำหรับที่อยู่ใดก็ได้
- **สำหรับกรณีฉุกเฉิน**: **ดาวน์โหลดชุดกู้คืน** ซึ่งต้องมีรหัสผ่านเข้าสู่ระบบ ดู [ชุดกู้คืน](offsite-recovery.md#recovery-kit)

## การแจ้งเตือน {#notifications}

**การแจ้งเตือน** พร้อมการสรุป **รายงานข้อมูลสำรองที่ล่าช้า** และ **สรุปประจำสัปดาห์** ส่วน **ช่องทาง** เป็นรายการช่องทาง Unraid, ntfy, Gotify, Discord, Slack, Matrix, อีเมล, Apprise, webhook และ Healthchecks แต่ละช่องทางมีสวิตช์ของตัวเอง พร้อม **แจ้งเตือน** และ **ส่งทดสอบ** ดู [การแจ้งเตือน](notifications.md)

## ยืนยัน {#verify}

- **ตรวจสอบข้อมูลสำรอง**: ผลของ `restic check` ครั้งล่าสุดต่อส่วน พร้อม **ปลดล็อก** และ **ตัดทิ้ง** ใต้ **เพิ่มเติม** ในแต่ละแถว **ปลดล็อก** ล้างล็อกที่ค้างและเว้นล็อกที่ยังถูกต่ออายุอยู่ และ **ตัดทิ้ง** ใช้กฎการเก็บเมื่อสั่ง
- **การตรวจสอบอัตโนมัติ**: การตรวจกู้คืนตามกำหนดพร้อม **ตัวอย่างข้อมูล (%)** และเป้าหมายทดสอบ **ทดสอบการเริ่ม** ซึ่งกู้คืนคอนเทนเนอร์หนึ่งตัวไปเป็นสำเนาแยกและเริ่มมันด้วย **การทดสอบ DR นอกสถานที่ตามกำหนดเวลา** และ **ตรวจสอบการป้องกันการลบ** ซึ่งเป็นการทดสอบการแก้ไขข้อมูลตามกำหนด ดู [การซ้อม DR](offsite-recovery.md#dr-drills) และ [การทดสอบการแก้ไขข้อมูล](offsite-recovery.md#tamper-test)
- **ความผิดปกติ**: การตรวจจับ ความไว และสิ่งที่พบแบบไหนส่งข้อความ ดู [ความผิดปกติ](anomalies.md)

## ความปลอดภัย {#security}

- **รหัสผ่าน**: รหัสผ่านเข้าสู่ระบบ อย่างน้อย 12 ตัวอักษร การเปลี่ยนหรือล้างต้องใส่รหัสปัจจุบัน และถ้าเปิดการยืนยันตัวตนสองขั้นตอนอยู่ก็ต้องใส่รหัสจากแอปด้วย
- **การยืนยันตัวตนสองขั้นตอน**: รหัสจากแอปยืนยันตัวตนเพิ่มจากรหัสผ่าน พร้อมรหัสกู้คืนแปดรหัสที่แสดงครั้งเดียว
- **พาสคีย์**: ลงชื่อเข้าใช้ด้วยคีย์บนโทรศัพท์ แล็ปท็อป หรือกุญแจความปลอดภัย ต้องมีชื่อโดเมนจริงและใบรับรองที่เบราว์เซอร์เชื่อถือ
- **แอป Android**: **โทรศัพท์จับคู่ด้วยคำสิบสองคำของกลุ่มได้** ซึ่งให้โทรศัพท์ที่จับคู่แล้วลงชื่อเข้าใช้ได้โดยไม่ต้องใช้รหัสผ่าน
- **การเข้ารหัส**: **เข้ารหัสข้อมูลสำรอง** เปิดอยู่โดยค่าเริ่มต้น

บางอย่างต้องใช้รหัสผ่านเข้าสู่ระบบ เช่น ชุดกู้คืนและการฝากคีย์ ดู [โมเดลความปลอดภัย](configuration.md#security-model)

## อินสแตนซ์ {#instances}

- **แสดงในแถบด้านข้างด้วย** ปักหมุดหน้าอินสแตนซ์ไว้ในแถบด้านข้าง
- **หลายเซิร์ฟเวอร์** เปิดส่วนต่าง ๆ ของกลุ่ม ได้แก่ **อินสแตนซ์** ซึ่งเป็นหน้าที่มีการ์ดของสมาชิกทุกตัว **ตัวรับ** และ **ดึง** ดู [อินสแตนซ์และบทบาท](offsite-recovery.md#roles)
- ลิงก์ไปยังหน้าอินสแตนซ์ พร้อมส่วนที่เปิดอยู่

## การจับคู่ {#pairing}

**การจับคู่** พร้อม **สร้างวลี** หรือ **ป้อนวลี** การ์ดขั้นตอน ชื่อของอินสแตนซ์นี้ อุปกรณ์ที่รอ **อนุมัติ** การ์ด **รีเลย์** พร้อมสี่แบบและ **สิ่งที่รีเลย์เห็น** สมาชิกของกลุ่ม และ **เซิร์ฟเวอร์ ZFS ที่ไม่มี BombVault** สำหรับปลายทางเรพลิกาผ่าน SSH ดู [การจับคู่อินสแตนซ์](offsite-recovery.md#pairing) และ [ส่งไปยังเซิร์ฟเวอร์ ZFS](zfs-datasets.md#replica-push)

## การเชื่อมต่อ {#integrations}

- **เซิร์ฟเวอร์ MCP**: คีย์สำหรับผู้ช่วย AI, **เลือกไคลเอนต์** และบันทึกของแต่ละคีย์ ดู [เซิร์ฟเวอร์ MCP](mcp.md)
- **โทเคน API**: โทเคนที่ตั้งชื่อสำหรับสคริปต์และแดชบอร์ด ดู [โทเคน](api.md#tokens)
- **บริการ**: **Home Assistant** ผ่าน MQTT, **ค้นหาในเครือข่าย** (mDNS ในชื่อ `bombvault.local`) และ **เปิดเผย /metrics** สำหรับ Prometheus พร้อม **โทเค็น scrape (ไม่บังคับ)** ดู [Home Assistant](api.md#home-assistant) และ [ค้นหา BombVault ในเครือข่าย](api.md#mdns)
- **วิดเจ็ตแดชบอร์ด**: โทเค็นแบบอ่านอย่างเดียวและที่อยู่สำหรับแดชบอร์ดใดก็ได้ที่แสดง iframe เช่น Homepage หรือ Heimdall โดยแสดงเฉพาะบันทึกกิจกรรมสด ดู [วิดเจ็ตแดชบอร์ด](api.md#dashboard-widget)
- **SSH ของโฮสต์**: กุญแจสาธารณะของ BombVault และ **ทดสอบการเชื่อมต่อ** สำหรับการสำรอง VM และชุดข้อมูล ZFS และการแจ้งเตือน Unraid ดู [คู่มือการสำรอง VM](vm-backup-ssh-setup.md)

## แอป {#apps}

- **แอป Android**: APK ของรุ่นที่เซิร์ฟเวอร์ของคุณรันอยู่ พร้อมคิวอาร์โค้ด และรายการบน F-Droid ดู [แอป Android](android.md#install)
- **ParleyPort**: คอนเทนเนอร์รีเลย์ พร้อมเทมเพลต Unraid และคำสั่ง Docker ที่เริ่มมัน
- **BombVault Widget**: ไทล์บนแดชบอร์ด Unraid ที่แสดงบันทึกกิจกรรมของ BombVault และรอบถัดไป เมื่อมีการเชื่อมต่อ SSH ไปยังโฮสต์ การ์ดติดตั้งและลบปลั๊กอินให้เอง ถ้าไม่มี มันจะให้ที่อยู่ `.plg` เพื่อติดตั้งที่ **Plugins, Install Plugin**

## ระบบ {#system}

- **ส่งออก / นำเข้าการตั้งค่า**: การกำหนดค่าทั้งหมดของคุณเป็นไฟล์ JSON พกพา จะมีหรือไม่มีข้อมูลรับรองก็ได้ การนำเข้าแสดง **ไฟล์นี้ประกอบด้วย** ก่อน และเว้นลิงก์ไปยังปลายทางที่จัดเก็บที่ไม่มีแล้ว **เข้ารหัสการส่งออกด้วย age** ปิดผนึกการส่งออกแบบธรรมดา ZIP ของแฟลช และชุดกู้คืนสำหรับ **ผู้รับ age** ที่คุณระบุ ดู [การตั้งค่าแบบพกพา](configuration.md#portable-settings-export-and-import)
- **ประสิทธิภาพ**: **เธรดซีพียู (0 = ทั้งหมด)**, **ขีดจำกัดขนาดแคช (MB, 0 = ไม่จำกัด)** สำหรับแคชของ restic ใต้ `/config` และ **ขีดจำกัดหน่วยความจำต่อการสำรองข้อมูล (MiB, 0 = ไม่จำกัด)** ซึ่งเป็นขีดจำกัดแบบอ่อนที่ทำให้การสำรองขนาดใหญ่ช้าลงแทนที่จะถูกฆ่าเพราะหน่วยความจำหมด

## ข้อมูล {#info}

- **รุ่น**: BombVault, GlimStone, restic และ rclone พร้อม **ตรวจหาอัปเดต** และ **ใหม่** ซึ่งนับการเปลี่ยนแปลงที่คุณยังไม่ได้เห็นและเปิดหน้าต่างที่แสดงการเปลี่ยนแปลงเหล่านั้น
- **ความช่วยเหลือ**: **คู่มือ** เปิดเอกสารนี้ และ **รายงานบั๊ก** ดาวน์โหลด ZIP ที่ปกปิดข้อมูลสำหรับ issue บน GitHub ต้องมีรหัสผ่านเข้าสู่ระบบ
- **เกี่ยวกับ BombVault**: โปรเจกต์ ใบอนุญาต และวิธีติดต่อผู้เขียน
