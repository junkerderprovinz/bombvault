# الميزات

فهرس موجز لما يفعله BombVault. كل سطر يقود إلى الصفحة التي تشرحه.

## نطاق النسخ الاحتياطي {#backup-scope}

- **الحاويات**: مجلد appdata وتعريف الحاوية، مع اختيار المجلدات لكل حاوية. [النسخ الاحتياطية والعناصر](backups.md#what-is-saved)
- **الأجهزة الافتراضية**: صور الأقراص وXML وUEFI NVRAM عبر SSH، مع إيقاف سليم أو لقطة حية أو الكتل المتغيرة فقط. الأجهزة ذات لقطات Unraid والأقراص على zvol مدعومة بالكامل. [نسخ الأجهزة الافتراضية](vm-backup-ssh-setup.md)
- **Flash**: كامل فلاش USB لـ Unraid، مع تصدير ZIP مجدول. [النسخ الاحتياطية والعناصر](backups.md#settings-tab)
- **النسخ الذاتي**: إعدادات BombVault نفسه وبيانات اعتماده. [معالج الطوارئ](offsite-recovery.md#emergency)
- **المجلدات**: أي مجلد على الخادم كمجموعة مجلدات. [إضافة مجلد](backups.md#add)
- **مجموعات بيانات ZFS**: شجرة مجموعات بيانات تُقرأ من لقطة واحدة، مع إمكان استعادة الملفات المفردة ونسخة طبق الأصل اختيارية على خادم ZFS ثانٍ. [مجموعات بيانات ZFS](zfs-datasets.md)
- **تفريغات قواعد البيانات**: PostgreSQL وMySQL وMariaDB، تُفرَّغ من الخادم العامل إلى نقطة استعادة خاصة بها. [تفريغات قواعد البيانات](backups.md#database-dumps)

## النسخ الاحتياطية وصفحات العناصر {#backups}

- **قائمة واحدة** ببلاطات و**عوامل التصفية** و**ترتيب** و**بحث**، وآخر أربعة عشر تشغيلًا لكل صف كشريط. [القائمة](backups.md#list)
- **التحديد كما في مدير الملفات**، ونسخ التحديد أو إيقافه مؤقتًا على الخادم. [تحديد عدة عناصر](backups.md#select)
- **صفحة لكل عنصر** بتبويبات **النسخ الاحتياطية** و**الإعدادات** و**تحقق**. [صفحة العنصر](backups.md#entry-page)
- **الوسوم والمقارنة** للقطات، و**تصدير** كـ tar أو zip أو مستودع restic. [تبويب النسخ الاحتياطية](backups.md#backups-tab)
- **أنماط الاستبعاد** مع معاينة حية، واستبعادات موصى بها للتطبيقات المعروفة. [أنماط الاستبعاد](backups.md#excludes)
- **أوامر قبل وبعد**، و**إيقاف حاويات أخرى** مع إعادة تشغيل مشروطة بالسلامة بترتيب التبعيات. [الأوامر والحاويات الأخرى](backups.md#commands)
- **عندما يكون التطبيق مشغولًا**: تنتظر النسخة المجدولة Plex أو Jellyfin أو Emby أو فحصك الخاص أو حركة هادئة، وتعيد المحاولة وحدها. [عندما يكون التطبيق مشغولًا](backups.md#app-busy)
- **لقطة بدل الإيقاف**: تتوقف الحاوية على ZFS بضع ثوانٍ فقط. [الجداول](schedules.md#snapshot-instead-of-stop)
- **عمليات تصدير عادية**، مختومة اختياريًا بـ age. [عمليات التصدير العادية](backups.md#exports)

## الاستعادة {#restore}

- **صفحة ونافذة واحدة** لكل الأنواع، مع النسخة الموصى بها محددة مسبقًا. [الاستعادة](restore.md)
- **بجانب الأصل** افتراضيًا، و**استبدال الأصل** ينسخ الحالة الحالية أولًا. [نافذة الاستعادة](restore.md#window)
- **ملفات مفردة** إلى مجلد أو إلى مكانها. [استعادة ملف واحد](restore.md#example-single-file)
- **عدة عناصر دفعة واحدة**، كل منها من نسخته الموصى بها أو من لحظة واحدة. [استعادة عدة عناصر](restore.md#several)
- **Stacks كاملة لـ Compose**، تبدأ بترتيب التبعيات. [استعادة stack](restore.md#stacks)
- **تُعاد الحاويات والأجهزة الافتراضية** على الصورة التي كانت تعمل عليها، مع المعالج الرسومي والحدود والروابط. [ما الذي يعود](restore.md#kinds)
- **فحوصات قبل الاستعادة**، وقائمة بما تغيّره. [نافذة الاستعادة](restore.md#window)
- **Flash كملف ZIP**، وإضافة واحدة في كل مرة إلى الفلاش العامل. [ما الذي يعود](restore.md#kinds)
- **ZFS** إلى مجموعة البيانات مع لقطة أمان، أو إلى مجلد، أو إلى مجموعة بيانات جديدة بخصائصها. [مجموعات بيانات ZFS](zfs-datasets.md#restore)
- **معالج الطوارئ** لخادم مفقود، بحقيبة الاستعادة أو عبر المجموعة أو بالمفتاح المكتوب. [معالج الطوارئ](offsite-recovery.md#emergency)
- **من مجلد نسخ احتياطية قديم**، و**الاستيراد من إضافة Appdata.Backup**، و**مهام من Duplicati أو Duplicacy** لتحويل مهام النسخ الاحتياطي في هاتين الأداتين إلى مجموعات مجلدات. [مصادر أخرى](restore.md#other-sources)

## التخزين والجدولة {#storage-scheduling}

- **وجهات** من كل نوع: مجلدات محلية وSMB وWebDAV وSFTP وrest-server وS3 ومحركات سحابية وأي rclone remote. [الوجهات](offsite-recovery.md#destinations)
- **بيانات الاعتماد**: قائمة واحدة مع افتراضي. [بيانات الاعتماد](offsite-recovery.md#sign-ins)
- **مجلدات خاصة** على هذا الخادم أو في وجهة. [المجلد الخاص بقسم](offsite-recovery.md#own-folder)
- **3-2-1 كتدفق** حيث كل سطر مفتاح، و**التوزيع لكل عنصر**. [التوزيع لكل عنصر](offsite-recovery.md#placement)
- **نسخ خارج الموقع** إلى عدة أماكن لكل قسم، مع حدود النطاق والضغط وفئات التخزين البارد وإبطاء أثناء بثّ Plex. [النسخ خارج الموقع](offsite-recovery.md#off-site-copies)
- **مستودعات مباشرة** مسرودة تحت **يُنسخ احتياطيًا إلى هنا مباشرة**. [المستودعات المباشرة](offsite-recovery.md#direct-repositories)
- **الاحتفاظ كخط زمني**: **قصير** أو **متوازن** أو **طويل** أو **قيم مخصصة** لكل وجهة، مع قواعد لكل قسم. [مدة الاحتفاظ](offsite-recovery.md#keep)
- **نقل تاريخ قسم**، و**إزالة الوجهة** مع نسخها أو بدونها. [النقل والإزالة](offsite-recovery.md#move-remove)
- **جداول تُقرأ كجمل**، وشريط **الأسبوع**، ونسخة شاملة، وخطط لكل قسم وخطة خاصة لكل عنصر. [الجداول](schedules.md)
- **تدارك النسخ الفائتة**، وترتيب يدوي، وتحديثات بعد نسخة ناجحة. [الجداول](schedules.md)

## الرؤية والتحقق والمراقبة {#insight-verification-monitoring}

- **النظرة العامة**: رأس الحالة، و**يحتاج إلى اهتمام**، و**حالة الحماية**، وتوقع التخزين، والتاريخ، وبطاقات اختيارية. [نظرة عامة](overview.md)
- **اكتشاف الحالات الشاذة** لكل عنصر، ويحتفظ أيضًا بالنسخ القديمة حين ينهار مصدر. [الحالات الشاذة](anomalies.md)
- **فحص الاستعادة** بعد أول نسخة، و**اختبار التشغيل** في نسخة معزولة. [تبويب تحقق](backups.md#verify-tab)
- **فحوصات مجدولة واستعادات تجريبية** من النسخة خارج الموقع. [تمارين DR](offsite-recovery.md#dr-drills)
- **الحجم حسب المجلد**، ولماذا كانت نسخة بطيئة. [ما يخبرك به تشغيل](backups.md#run-notes)
- **الإشعارات**: قائمة قنوات لـ Unraid وntfy وGotify وDiscord وSlack وMatrix والبريد وApprise وأي webhook وHealthchecks، لكل منها قاعدتها الخاصة، مع ملخص أسبوعي وتقرير تأخر. [الإشعارات](notifications.md)
- **Prometheus**، وجهاز Home Assistant، وواجهة HTTP API وmDNS. [واجهة API والتكاملات](api.md)
- **بلاغ خطأ**: ملف ZIP منقّح لمسألة GitHub. [استكشاف الأخطاء](troubleshooting.md#still-stuck)

## الحماية من برامج الفدية {#ransomware-protection}

- **الحماية من الحذف (append-only)**، يفرضها الجانب البعيد ويثبتها اختبار عبث. [الحماية من الحذف](offsite-recovery.md#delete-protection-append-only)
- **القبول بدون حماية من الحذف** لمكان لا يستطيع رفض الحذف. [الحماية من الحذف](offsite-recovery.md#delete-protection-append-only)
- **الحذف النهائي للنسخ يتطلب تسجيل دخولك أنت** متى ضُبطت كلمة مرور دخول، ولا يستطيعه هاتف مقترن. [نموذج الأمان](configuration.md#security-model)
- **حقيبة الاستعادة**، مختومة اختياريًا بـ age، و**حافظ مفتاح** في مجموعتك. [حقيبة الاستعادة](offsite-recovery.md#recovery-kit)، [حافظ المفتاح](offsite-recovery.md#key-keeper)

## عدة خوادم {#several-servers}

- **اقتران بالكلمات الاثنتي عشرة**، مشفّر من طرف إلى طرف، مباشرة أو عبر مُرحِّل. [اقتران المثيلات](offsite-recovery.md#pairing)
- **صفحة المثيلات** مع المجموعة كشبكة وأدوار **المستقبِل** و**الساحب** و**خادم ZFS** و**حافظ المفتاح**. [المثيلات والأدوار](offsite-recovery.md#roles)
- **خادم مستقبِل** يُعدّ لك، في وضع append-only. [الخادم المستقبِل](offsite-recovery.md#receiving-server)
- **مستودع مشترك** تنسخ إليه عدة خوادم، فيُحفظ ما تشترك فيه مرة واحدة. ولا يقلّمه إلا الخادم الذي يحتفظ به. [مستودع مشترك](offsite-recovery.md#shared-repository)

## مساعدو الذكاء الاصطناعي (MCP) {#mcp}

يتيح خادم MCP المدمج لمساعد قراءة حالة النسخ الاحتياطية والتغطية وسجل التشغيل ونقاط الاستعادة، ومع مفتاح يسمح بذلك بدء نسخة احتياطية. تبقى الاستعادات والحذف والتقليم والإعدادات في واجهة الويب. [خادم MCP](mcp.md)
