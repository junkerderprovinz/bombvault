# 设置

**设置**有十四个磁贴。每个磁贴是一页卡片，每次更改都会在你操作时写入，控件会短暂闪一下，服务器拒绝时则会抖一下。少数几个窗口保留了**保存**按钮，因为做到一半就保存会不安全，例如登录凭据或登录密码。说明放在每个控件旁边的 (i) 气泡里。

在设置的任何地方按 `/` 或 Ctrl+K 可以搜索全部设置，页面在旧版本里用过的名称也能搜到。磁贴的顺序可以在**外观**下更改。当页面旁边的一列磁贴会把页面挤得太窄时，例如窗口约 1200 像素宽或在手机上，磁贴会变成页面上方一条可以横向滚动的带子。

本页列出每个磁贴及其卡片，并链接到深入讲解每一项的页面。

## 常规 {#general}

- **分区**开关每个分区：**容器**、**虚拟机**、**闪存**、**文件夹**、**ZFS 数据集**和**自我备份**。关闭的分区不会按任何计划备份，包括条目自己的计划，它的条目也不计入。**立即备份**仍然可用。**闪存**只在 Unraid 上显示。
- **容器**里是适用于所有容器的设置，例如**自动数据库转储**。只影响单个容器的设置在它自己的页面上。参见[数据库转储](backups.md#database-dumps)。

## 外观 {#look}

- **外观**：**语言**（42 种语言）、**主题**（**深色**、**浅色**或**系统**）、**圆角**、**动画**（**关闭**、**轻微**、**狂野**或**狂暴**）、**安静的通知**（隐藏保存确认之类的成功提示），以及**设置页面的顺序**，在这里按住一个磁贴拖到位置上，或使用 Alt 加方向键。
- **标签**：控件显示多少内容，分别针对**按钮**、**侧边栏**、**标签页**和**底栏**：**文字**、**文字和符号**、**符号**，或者**响应式**，它只显示符号，指向时才滑出文字。**侧边栏**只影响桌面布局，**底栏**只影响手机布局。
- **颜色**：一个**强调色**，或者**彩虹模式**，列表的每一行从八种颜色的调色板里得到自己的颜色。彩虹模式还带有**迪斯科模式**（颜色缓缓滑向下一种）、**响应模式**（一行的颜色只在你指向它、它在运行或被选中时才显示）、**颜色轮换**和**调色板**本身。

BombVault 把外观保存在服务器上。第一次来的浏览器会接管它。当你的系统要求减少动效时，这总是优先于**动画**。

## 计划 {#schedule}

**一周**、带**备份何时运行**的**全部备份**、**启动后补做错过的备份**和**前后命令**、带**按分区的异地副本**的**按分区的计划**、**已计划的条目**、带**备份后重启**的**顺序**、**用快照代替停止**、**备份后的更新**和**备份前空闲**。参见[计划](schedules.md)。

## 目标 {#storage-locations}

- **同时显示在侧边栏**把目标页面固定到侧边栏。
- 你的存储位置列表，带**添加目标**。点击会打开一个位置的页面，参见[存储位置的页面](offsite-recovery.md#location-page)。
- **凭据**：已保存的凭据，带默认星标，参见[登录凭据](offsite-recovery.md#sign-ins)。
- **按分区划分的目标**：3-2-1 流程，每一行都是一个开关，参见[按分区的默认设置](offsite-recovery.md#placement-defaults)。
- **存储库**：为单个条目创建的仓库，参见[按条目放置](offsite-recovery.md#placement)。
- **保留多久**指向存储位置，保留规则在那里设置，**预览**会在**下次运行将删除的内容**发生之前，按仓库和按条目显示出来。它不改变任何东西，也不加锁，所以备份运行时也能回答。
- **异地副本**：每个分区一行，带**测试连接**、**立即复制**和**设置**或**编辑**，参见[异地副本](offsite-recovery.md#off-site-copies)。
- **异地带宽**：每次复制的**上传限制 (KiB/s)** 和**下载限制 (KiB/s)**。0 表示不限。

在 Plex、Jellyfin 或 Emby 串流时降低上传限制的**串流**卡片，位于目标页面本身。

## 恢复 {#restore}

- 一个指向**恢复**页面的链接。
- **还原文件夹**：恢复到文件夹时用的**默认还原文件夹**，带**每个分区一个子文件夹**和每个分区的**例外**。参见[恢复到文件夹时放在哪里](restore.md#folders)。
- **容器镜像仓库**：私有镜像仓库的登录凭据，例如需要赞助才能访问的 `ghcr.io` 镜像。恢复用它们拉取缺失的镜像，备份后的更新用它们检查较新的镜像。公开镜像不需要它们就能拉取。**添加镜像仓库**提供公共镜像仓库、自托管的、云服务商的，以及用于任意地址的**其他镜像仓库**。
- **应对紧急情况**：**下载恢复工具包**，需要登录密码。参见[恢复工具包](offsite-recovery.md#recovery-kit)。

## 通知 {#notifications}

带**通知**、摘要、**报告逾期的备份**、**Unraid 通知**和**每周摘要**的**通知**，带 Webhook、Apprise、Matrix、Gotify 和邮件 (SMTP) 的**渠道**，以及 **Healthchecks**。参见[通知](notifications.md)。

## 验证 {#verify}

- **检查备份**：每个分区上一次 `restic check` 的结果，每一行的**更多**下有**解锁**和**清理**。**解锁**清除过期的锁，**清理**按需应用保留规则。
- **自动检查**：计划的恢复检查，带**数据抽样 (%)** 和测试目标，**启动测试**（它还会把一个容器恢复成隔离的副本并启动它）、**计划的异地 DR 演练**和**检查删除保护**（计划的防篡改测试）。参见 [DR 演练](offsite-recovery.md#dr-drills)和[防篡改测试](offsite-recovery.md#tamper-test)。
- **异常**：检测、灵敏度，以及哪些发现会发送消息。参见[异常](anomalies.md)。

## 安全 {#security}

- **密码**：登录密码，至少 12 个字符。更改或清除它时会要求输入当前密码，开启两步验证时还要输入验证码。
- **两步验证**：在密码之外再加一个来自验证器应用的验证码，附带八个只显示一次的恢复码。
- **通行密钥**：用手机、笔记本电脑或安全密钥上的密钥登录。它们需要真实的域名和浏览器信任的证书。
- **Android 应用**：**允许手机用群组的十二个单词配对**，让已配对的手机不用密码就能登录。
- **加密**：**加密备份**，默认开启。

有些事情需要登录密码，例如恢复工具包、密钥托管和永久删除备份。参见[安全模型](configuration.md#security-model)。

## 实例 {#instances}

- **同时显示在侧边栏**把实例页面固定到侧边栏。
- **多台服务器**开启组的各个部分：**实例**（为每个成员提供一张卡片的页面）、**接收端**和**拉取**。参见[实例和角色](offsite-recovery.md#roles)。
- 一个指向实例页面的链接，附带已开启的部分。

## 配对 {#pairing}

带**生成口令**或**输入口令**的**配对**、各步骤卡片、本实例的名称和**已知地址**、带四种形式和**中继能看到什么**的**中继**卡片、组的成员，以及用于通过 SSH 作为副本目标的**没有 BombVault 的 ZFS 服务器**。参见[配对实例](offsite-recovery.md#pairing)和[推送到 ZFS 服务器](zfs-datasets.md#replica-push)。

## 集成 {#integrations}

- **MCP 服务器**：AI 助手的密钥、**选择客户端**和每个密钥的日志。参见 [MCP 服务器](mcp.md)。
- **API 令牌**：用于脚本和仪表盘的命名令牌。参见[令牌](api.md#tokens)。
- **服务**：通过 MQTT 的 **Home Assistant**、**在网络中查找**（mDNS，名为 `bombvault.local`）以及为 Prometheus 准备的**暴露 /metrics**，带**抓取令牌（可选）**。参见 [Home Assistant](api.md#home-assistant) 和[在网络上找到 BombVault](api.md#mdns)。
- **仪表盘小组件**：一个只读令牌和一个地址，用于任何显示 iframe 的仪表盘，例如 Homepage 或 Heimdall，只带实时活动日志。参见[仪表盘小组件](api.md#dashboard-widget)。
- **主机 SSH**：BombVault 的公钥和**测试连接**，用于虚拟机和 ZFS 数据集备份以及 Unraid 通知。参见[虚拟机备份指南](vm-backup-ssh-setup.md)。

## 应用 {#apps}

- **Android 应用**：你的服务器所运行版本的 APK，带二维码，以及 F-Droid 的列表。参见 [Android 应用](android.md#install)。
- **ParleyPort**：中继容器，带它的 Unraid 模板和启动它的 Docker 命令。
- **BombVault Widget**：Unraid 仪表盘上的一个磁贴，显示 BombVault 的活动日志和下一次运行。有主机 SSH 连接时，这张卡片会自己安装和移除插件。没有的话，它会给你 `.plg` 地址，在 **Plugins, Install Plugin** 下安装。

## 系统 {#system}

- **导出 / 导入设置**：你的整个配置，导出为可携带的 JSON 文件，可带或不带凭据。导入时会先显示**此文件包含**，并忽略指向已不存在的存储位置的链接。**使用 age 加密导出**会为你列出的 **age 收件人**封存普通导出、Flash ZIP 和恢复工具包。参见[可携带的设置](configuration.md#portable-settings-export-and-import)。
- **性能**：**CPU 线程数 (0 = 全部)**、restic 在 `/config` 下缓存的**缓存大小限制（MB，0 = 不限）**，以及**每次备份的内存上限 (MiB, 0 = 无)**，这是一个软限制，让大型备份变慢，而不是因内存不足被杀掉。

## 信息 {#info}

- **版本**：BombVault、GlimStone、restic 和 rclone，带**检查更新**和**新增**，后者会统计你还没看过的更改，并打开一个列出它们的窗口。
- **帮助**：**手册**打开这份文档，**错误报告**下载一个去除敏感信息的 ZIP，用于 GitHub issue。它需要登录密码。
- **关于 BombVault**：项目、它的许可证，以及如何联系作者。
