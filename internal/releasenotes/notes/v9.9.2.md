A forgotten login password can be reset from the login page.

## ✨ Added

- **Forgot password?** on the login page. BombVault writes a code to its container log (on Unraid: Docker tab, BombVault icon, **Logs**). Enter that code and a new password on the login page and you are signed in. A code is valid for 10 minutes and five tries. The reset also switches two-factor authentication off and ends every other session. Reading the container log takes access to the host, so somebody who only reaches the web interface cannot reset anything.

## 🌐 Translations
