Running restore checks are now visible in the activity log, and the log's date format matches the rest of the app.

## Fixed

- **Restore checks, tamper tests and the flash-ZIP export now show in the activity log WHILE they run (#109).** Scheduled restore checks could keep disks busy for a while with the log showing nothing until they finished. All three now publish a live line ("Restore check running — Containers …") that updates in place and hands over cleanly to the finished entry — same as backups and replication. They deliberately don't block the backup/restore buttons.
- **The log's date format can no longer disagree with the rest of the app (#108).** The activity log resolved its date locale differently from every other date in the UI, so on some systems (e.g. an English browser with a Portuguese region) only the log showed US-style dates. It now uses exactly the same system-default formatting as the rest of the app.
