A refused off-site connection now names the word that is wrong, instead of repeating the server's 401, and the interface moves to GlimStone 1.8.0.

## 🐛 Fixed

- **The 401 explanation added for [#194](https://github.com/junkerderprovinz/bombvault/issues/194) never reached anyone.** It recognised an error only when the repository URL sat inside the message, and the message BombVault shows never carries one: restic prints the URL on its "Is there a repository at the following location?" line, which the error builder steps over as boilerplate to reach the line that names the cause. So the connection test went on showing a bare `401 Unauthorized`, two releases after the explanation shipped. Every test case written for it had been composed by hand, each one with a URL in it, which is why nothing failed. It now also recognises restic's own REST-backend wording, and the case taken off a reporter's screen is in the test.

- **The About card's GlimStone link opened a 404.** It said 1.7.5, which was a changelog heading and never a release: the language folded 1.7.1 through 1.7.10 into 1.8.0. Every version on that card is a link to its own tag's release page, so the number was not merely stale. The number now travels with the files it describes rather than sitting in a constant beside the card, which is what let it drift in the first place.

## ⚡ Improved

- **A refused connection test says which two names disagree** ([#194](https://github.com/junkerderprovinz/bombvault/issues/194)). A rest-server started with `--private-repos` gives each user only the tree under its own name, so the first part of the repository URL has to be the htpasswd user. When a test is refused and those two differ, BombVault now says which name it signed in with and which name the URL begins with, rather than listing what usually goes wrong. Both values were in front of it all along; it had never compared them. In #194 the difference was one character, an underscore in the credential set where the generated recipe writes a hyphen, and it survived three rounds of screenshots.

- **The off-site wizard says it before the test is run.** The same comparison sits under the repository URL while it is being filled in. It is a hint and not a refusal: a server running without `--private-repos` is free to disagree, and it stays quiet wherever it would be guessing, including a URL with a single path segment, where a 401 means a wrong password instead.

## 🎨 Design

The interface is on **GlimStone 1.8.0** (from 1.7.5).

- **The rail is a card, not a wall.** It carries the same radius and the same ground margin as every other card, with the background showing on all four sides. The page gutter moved to the frame that holds the rail and the content, so one number now produces the gap around the rail, the gap around the content and the gap between them.
- **Hover moves up the surface ramp, all the way up.** A control filled with the raised surface had nowhere to hover to and reached back down to a tone below the one it was resting on, so it went four units darker under the pointer instead of lifting. There is a third tier now, lighter on dark and darker on light.
- **The wheel steps a picker again.** A closed dropdown answers the mouse wheel, both the app's own listbox (on the language picker, where a list of 42 should not cost a click first) and every native one still standing. It clamps at both ends rather than wrapping: one notch too many should not land a value from the other end of the list.
- **A new button shape for the small row action**, square while the label setting paints no words and an ordinary labelled button while it does, with the glyph filling half the square rather than two thirds of it. The two reset controls beside the colour rows are deliberately unchanged.

## 🌐 Translations

- One new string in all 42 languages: the off-site wizard's warning that the repository URL and the credentials name different users.
