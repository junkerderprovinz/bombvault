A patch for off-site copies between two S3 servers.

## 🐛 Fixed

- **An off-site copy from S3 to S3 failed with "The Access Key Id you provided does not exist".** When a section's own folder is on an S3 server and its off-site copy goes to another one, the copy opened the own folder with the off-site server's key. Both ends now sign in with their own keys. The same goes for a repository that uses the shared cloud credentials. ([#358](https://github.com/junkerderprovinz/bombvault/issues/358))
- **The preview in Add storage location showed `s3:s3:http://...`** when the endpoint was typed with `s3:` in front. The saved location was always right; the preview now matches it. ([#358](https://github.com/junkerderprovinz/bombvault/issues/358))

## ⚡ Improved

- **"This location lies inside another repository or target" now says which one.** The message ends with the location in the way, so you can find it and remove it. ([#358](https://github.com/junkerderprovinz/bombvault/issues/358))
