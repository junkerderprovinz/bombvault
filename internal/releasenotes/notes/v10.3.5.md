BombVault 10.3.5 lets the trial restore pass on Unraid's default restore folder.

## 🐛 Fixed

- **A trial restore no longer fails when only file metadata could not be set.** The default restore folder sits on the `/mnt/user` share, which refuses ownership and `trusted.*` extended attributes. restic still wrote every file, but the trial restore stopped at that error, so Containers and Folders could never go green under Trial restore. It now carries on and compares the restored files and bytes with the snapshot, and only a real difference fails it. A normal restore already worked this way. Thanks to @one4spl, who found the line. ([#379](https://github.com/junkerderprovinz/bombvault/issues/379))
