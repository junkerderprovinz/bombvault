BombVault 10.3.4 lets a container's scheduled backup wait while somebody uses the app and try again on its own, instead of failing and waiting for you to press Try again.

## ✨ Added

- **A scheduled backup waits while the app is busy and tries again on its own.** A Pre-backup command that exits with code 75 defers it instead of failing it. The new **When the app is busy** card on a container's Settings tab sets how often it is tried again, an optional time window that may run past midnight, and how long it waits at most, then it gives up under Needs you or backs up anyway. The rest of the run goes on, the wait survives a restart, and you get one notice when it waits and one when it ends. A backup you start yourself always runs right away. ([#378](https://github.com/junkerderprovinz/bombvault/issues/378))
- **Ask Plex, Jellyfin or Emby before a scheduled backup.** The **Activity check** asks the media server whether anybody is watching, with Plex's own token from its Preferences.xml or an encrypted API key for Jellyfin and Emby. Paused sessions can stop counting after some minutes, and you choose whether a server that does not answer lets the backup run. BombVault asks the server directly and otherwise through curl or wget inside the container, which also reaches containers on br0 or macvlan. ([#378](https://github.com/junkerderprovinz/bombvault/issues/378))
- **Wait while the container sends data.** For apps without such a check, such as game servers or downloaders, a scheduled backup can wait while the container sent more than a rate you set within the last few minutes, read from Docker's own counters. ([#378](https://github.com/junkerderprovinz/bombvault/issues/378))

## 🐛 Fixed

- **The exclude previews say what the backup does.** On a phone the warning under a long exclude line no longer shrinks to a column one word wide. The ZFS preview warns about a line that names part of the snapshot path the backup reads, such as `.zfs`, `snapshot` or `bombvault-*`, which the backup ignores because it would leave a whole dataset out, and it counts the files of a child dataset once instead of twice.
