Settings survive a cleared browser, and they come back on their own.

## 🐛 Fixed

- **A cleared browser could wipe the look it was meant to restore** ([#191](https://github.com/junkerderprovinz/bombvault/issues/191)). Saving display settings replaced the whole set every time, and a browser sends what it has, not what it should have. A page still running in a tab whose site data had just been cleared therefore published its own emptiness on the next change, and the other ten settings were gone on the server as well, so reloading did not bring them back. Each setting is merged on its own now, and a browser with nothing to say no longer says anything.
- **The settings arrived but the page still showed defaults** ([#191](https://github.com/junkerderprovinz/bombvault/issues/191), second report). Restoring the look ended in a page reload, because the language and the advanced view are read once when the interface starts. That reload was allowed only once per tab, as a safeguard against reloading in circles, and a tab that was restored or that stayed open while its site data was cleared had already used it up. Nothing reloaded, and the page sat there in English on a white background with the right settings already stored. Each setting is applied where it stands now, so nothing has to reload and nothing can be skipped.
- Whether a Fleet peer card shows its scorecard is kept with the rest of the look, so it also survives a new browser.
