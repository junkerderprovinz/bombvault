## 🐛 Fixed

- **A cleared browser could wipe the look it was meant to restore** ([#191](https://github.com/junkerderprovinz/bombvault/issues/191)). Saving display settings replaced the whole set every time, and a browser sends what it has, not what it should have. A page still running in a tab whose site data had just been cleared therefore published its own emptiness on the next change, and the other ten settings were gone on the server as well, so reloading did not bring them back. Reported as three attempts in a row in Firefox and none in Brave, which differ in what they do to an open tab's running script when site data goes. Each setting is merged on its own now, and a browser with nothing to say no longer says anything.
