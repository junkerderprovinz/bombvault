BombVault on Unraid's dashboard: a native tile with one-click install, a cleaner borderless look — plus everything from the 6.8.3-6.9.0 series in one place.

## Added

- **Native Unraid dashboard tile.** The new companion plugin [bombvault-widget](https://github.com/junkerderprovinz/bombvault-widget) puts BombVault's live activity log on Unraid's own dashboard as a real tile: it shows up in the dashboard's tile management, has the native header with cog and collapse chevron, and renders the scrollable terminal-style log with your live data (10-second refresh, server-side proxy, read-only widget token).
- **One-click install from BombVault (Settings → System → Dashboard widget).** If your host SSH connection is set up, BombVault installs or removes the tile plugin for you through Unraid's regular plugin mechanism — it appears under Plugins like any other and can be removed anytime. Without SSH you get the manual .plg URL and a CA hint.
- **Embeddable activity-log widget (6.9.0).** A lightweight, iframe-ready widget page for Homepage, Organizr or any dashboard that embeds URLs — token-protected, 11 KB, with a live preview right in the settings.

## Changed

- **One visual language across the whole app.** Cards, panels and dialogs lose their outline borders — surfaces separate through background shading alone. Tabs, mode pills, day chips, source toggles and filter buttons switch from outlined to filled: the active one carries your accent colour, inactive ones sit flat with the standard hover. Status boxes become tinted, borderless surfaces. Form fields, row separators and focus rings keep their functional outlines.

## Fixed

- **The widget URL copy button works everywhere now (#112).** Copying silently failed outside secure contexts (plain HTTP); all copy buttons now fall back to the classic copy mechanism and only show "copied" when it actually worked.
- **Restore errors show the real cause (#110, 6.8.5)** — decoded from restic's JSON output instead of a bare "Fatal: There were N errors"; the metadata-only warning downgrade works again.
- **Every scheduled check leaves a trace (#109, 6.8.3-6.8.5):** restore checks, tamper tests and the flash-ZIP export appear live in the activity log; tamper tests record every outcome including "skipped" with the reason; off-site DR checks have their own distinguishable entries; the append-only check moved to Integrity & Maintenance and the tamper schedule says when it is inactive.
- **The removed-container reminder speaks clearly (#111, 6.8.5)** and fires only on the first skip.
- **Log dates follow your region (#108, 6.8.3)** — same system-default formatting as every other date in the app.
- **/metrics works in production again (6.9.0)** — it was swallowed by the web-app router.
