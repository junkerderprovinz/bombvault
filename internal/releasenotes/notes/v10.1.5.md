A patch for the activity log and the lint check.

## 🐛 Fixed

- **A running ZFS replica had no line in the activity log.** A backup shows "Backing up ... 32%" while it runs, but a replica showed nothing until it was done, so the log looked as if replications were no longer logged. The running replica now has its own line with its progress. ([#356](https://github.com/junkerderprovinz/bombvault/issues/356))
- **The Go lint check passes again.** Errors received from channels were discarded, and the lint tool is now pinned to one version so a new release of it cannot break the check.
