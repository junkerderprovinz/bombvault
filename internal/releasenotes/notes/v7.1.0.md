BombVault 7.1.0 adds two opt-in ways to make your backups cheaper to keep and safer to move off the box. Existing settings, schedules and repositories are untouched.

## Added

- **Cold and archival storage class for off-site backups.** On the Off-site tab you can now choose the S3 storage class for a native S3 repository, restricted to the tiers a restore can still read directly: Standard, Standard-IA, One Zone-IA, Intelligent-Tiering and Glacier Instant Retrieval. Archival pricing therefore never silently breaks a restore. The deep-archive tiers that first need an asynchronous thaw (Glacier Flexible Retrieval and Deep Archive) are deliberately left out. This applies to native S3 backends; rclone-based remotes continue to set their class in the rclone configuration.
- **Optional age encryption for the plain exports.** Your restic repositories are already encrypted. This adds an opt-in layer for the plain export artifacts that are not: the container and VM tar.gz files with their XML sidecars, and the flash ZIP. Add one or more recipients under Settings, either an age public key or an SSH public key, and each export is sealed for them; you decrypt it later off the box with the matching private key. As a safety rule, when encryption is on and no valid recipient is set, an export stops with a clear error instead of ever writing a plaintext file.

## Upgrading

Nothing to do. Both features are off by default, so this build behaves exactly like 7.0.0 until you turn one on.
