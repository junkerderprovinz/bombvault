Every scheduled check now leaves a trace in the activity log, and off-site DR checks are clearly labelled.

## Fixed

- **Tamper tests always show up in the activity log now (#109).** When the off-site repo is not a REST server (for example B2 or S3 object-lock immutability), the scheduled tamper test used to end without recording anything — the 08:00 schedule seemed to vanish. Every tamper run is now logged with an honest outcome: protected, FAILED, or skipped with the reason ("only REST repos are verifiable").
- **Off-site DR checks are distinguishable from local restore checks (#109).** Both used to log the identical "Restore check passed" line, so the DR proof was invisible in the log. The off-site DR drill now has its own entries — "Off-site DR check running …" live and "Off-site DR restore verified — Containers" when done — plus its own filter option.
