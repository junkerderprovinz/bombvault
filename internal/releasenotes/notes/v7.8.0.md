BombVault 7.8.0 makes backup errors visible and fixable straight from the dashboard, and fixes saving the VM backup order.

## ✨ Added

- **See and clear backup errors from the dashboard.** The error count is now clickable and opens a panel that lists every failed backup run with its time, domain, target name and error message. Identical errors that fired across many targets (for example "backup path not mounted" hitting every container after a reboot) are grouped into a single row with a count, so a systemic problem is obvious at a glance instead of scrolling past dozens of identical rows. You can filter the list the same way as the Activity Log, and acknowledge errors right there, one at a time or with "Mark all resolved", without ever touching the database. Acknowledged errors drop off the count.

## 🐛 Fixed

- **Saving the VM backup order no longer fails with "Invalid name" for VMs whose names contain spaces.** Names like "Windows 11" or "Home Assistant" were rejected by the stricter container-name check. The VM backup order now uses the VM-aware validator, matching the rest of the VM handling.
