BombVault 10.4.2 prunes an own folder in a storage location by that location's **How long to keep** card, which a fresh install never did. A section with nothing to back up no longer reads overdue, and a new one says **No backup yet** until its first run was due.

## ⚡ Improved

- **A new section says No backup yet.** Until a scheduled section's first run was due, the overview and Home Assistant stay neutral instead of showing a red Overdue. After that it reads overdue and alerts once. ([#407](https://github.com/junkerderprovinz/bombvault/issues/407))
- **Moving an own folder asks before keeping less.** If the new place's **How long to keep** card keeps less than the section's rule today, the move window asks first and can keep the current values under **Rules per section**. ([#407](https://github.com/junkerderprovinz/bombvault/issues/407))

## 🐛 Fixed

- **An own folder in a storage location follows its How long to keep card.** It was pruned by a shared rule no page showed, and a fresh install leaves that rule at 0, so nothing was ever pruned. **Rules per section** still wins, a section that was pruning keeps its retention on update, and one that kept everything starts following the card, named in the log. Thanks to @manilx for the clear screenshots. ([#407](https://github.com/junkerderprovinz/bombvault/issues/407))
- **A section with nothing to back up is never overdue.** A switched-on section without a scheduled entry read Overdue after every good run, and it reads Not scheduled. ([#407](https://github.com/junkerderprovinz/bombvault/issues/407))
- **Who prunes and the Protection status say what happens.** **Who prunes** names the card or a section's own values, and a section pruned by either no longer reads "No prune rule set". ([#407](https://github.com/junkerderprovinz/bombvault/issues/407))
- **Home Assistant reads ok only with a current section.** A section that is off or still waiting for its first backup no longer makes the status `ok`.
- **A pruned backup no longer blames an old own folder.** The restore probe's log line says the backup was pruned or deleted since.
