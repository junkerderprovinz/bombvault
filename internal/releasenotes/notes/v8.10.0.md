Animations start one level lower, a hidden Disco mode walks the rainbow palette, and the green flash at "Wild" is gone.

## ✨ Added

- **Disco mode**, hidden until you find it: every coloured row and item steps to the next colour in the palette once a second, for as long as Rainbow Mode is on. Turn Rainbow Mode on five times in a row to unlock it. It is a colour change, not an animation, so it costs nothing to run.
- **The hidden "Storm" animation level overrides the system's reduced-motion setting.** The three levels the picker offers still obey it. Storm takes five clicks on the same option, so nobody gets there without meaning to.

## 🔒 Security

- **rclone moves to 1.75.1**, which closes two vulnerabilities the image scanner flags as critical. They were the only two of the image's five criticals that are ours to move; the other three come from Perl in the Debian base. Both checksums are taken from rclone's own published sums for that release, and the build verifies them before installing.

## 🐛 Fixed

- **Animations at "Wild" no longer fade on a spring** ([#228](https://github.com/junkerderprovinz/bombvault/issues/228)). On Firefox/macOS the coloured badges flashed `#38FF38` a moment after loading. A spring curve drives its value past the target and back, which is the point for a distance and meaningless for opacity: the value stops at fully visible, so the fade finished early and then sat still for the rest of the animation. The movement keeps its spring; the fade runs on a curve that only eases.
- **Confirmed as the fix, and by the person who reported it.** What the report had narrowed down: "Off" and "Subtle" are clean, "Wild" is not, and the reporter renders in software already, so the graphics card was out. The remaining difference between those settings is that curve. A four-panel file then stepped through the change with nothing of this app in it: the panels that keep opacity on the springing curve flash, the one without it does not. On this build the green is gone at "Wild" on the reporter's own machine. One honest limit: those panels flashed without the green tint, so the small file reproduced the flash and not its colour, and the colour goes with the flash.
- **Animations start at "Subtle"**: 6px, no tilt, no scale. Nobody had chosen the top level, it was simply what shipped. **Wild** is unchanged and still available under Settings, General, Animations.
- **The page entrance no longer scales or tilts.** One spatial dial instead of three, so a page never asks the browser to redraw itself while the cards inside it animate. "Wild" is still clearly livelier than "Subtle": three times the travel, longer, on a curve that overshoots and settles.
- **"Storm" lost the largest values in the file** (3 degrees, 90%). It is the one level that animates for somebody who asked for less movement, so it is the last place that should be redrawing a whole page.
- **A strong-level choice made before the setting was renamed carries over** instead of being reset to the new default.
- **Stacked selectors no longer wear the same colour in the same column** in Rainbow Mode. Each one starts further along the palette, so the three label-mode rows read as three rows instead of one repeated three times.
- **A duplicate animation definition** in the stylesheet, declared twice identically, so the second one silently won.
