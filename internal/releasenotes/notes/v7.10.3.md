BombVault 7.10.3 fixes a display bug where a failed connection test on an additional off-site target could crush that target's repository path down to one character per line.

## 🐛 Fixed

- **A long "Test connection" error message on an additional off-site target could squeeze the target's repository path into an unreadable single-character column.** The error text had no maximum width, so its container grew to fit the whole message on one line and, since that side of the row refuses to shrink, took all the available space from the repository-path column next to it - which does shrink, and wraps character-by-character once squeezed down far enough. The error text now wraps within a fixed width instead, the same way equivalent error messages elsewhere in the app already do, so the repository path keeps its normal width regardless of how long the error is.
