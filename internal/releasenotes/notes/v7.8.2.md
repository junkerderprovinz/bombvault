BombVault 7.8.2 extends the 7.8.1 restore-destination fix to VM restores, which shared the same underlying bug but hadn't been fixed yet.

## 🐛 Fixed

- **A remapped VM restore's destination folder is no longer left unreadable and root-owned.** Cross-instance container restores got a fix for this in 7.8.1: the destination folder restic creates during a remapped restore never had its own readability or owner restored, only the files inside it. VM restores use the exact same restic mechanism and had the identical problem, just not yet fixed. It now gets the same treatment as containers: the destination folder is created readable up front, and its original owner and mode are restored after a successful restore.

## Upgrading

Just pull the new image.
