BombVault 7.8.2 fixes off-site "Test connection" showing a generic "not reachable" instead of the real reason.

## 🐛 Fixed

- **Off-site "Test connection" now shows the real reason it failed.** A misconfigured rclone remote, wrong credentials, or an unreachable backend all showed the same generic "not reachable" with no detail. The actual error restic/rclone reported is now shown instead, so a bad remote type or a typo in the config is obvious immediately instead of a dead end.
